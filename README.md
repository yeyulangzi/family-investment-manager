**家庭投资管理（Family Investment Manager）** 是一个 Agent Skill（适用于 Claude Code / Codex / VS Code Copilot 等 AI 编程助手）：以**家庭财务基准**（资产表、安全垫、IPS、风险桶）为锚点，用 1 个编排层 + 26 个专业子 Agent + 4 份投资方法论 + 9 套报告模板 + 1 个金融验算工具，把每一次投资决策变成一条有纪律、可复盘、有闸门的完整流水线——而不是给你一个没有执行含义的市场观点。

> ⚠️ **任何交易建议必须通过五道闸门**：资金属性 → 家庭安全 → 风险桶 → 标的估值 → 执行行为。它不承诺收益、不构成投资建议。

## 能力总结

Family Investment Manager 是一个面向个人投资者的家庭投资管理 Skill。它以「家庭财务基准优先于市场观点」为核心设计：先读你的家庭资产表、财务宪法（安全垫）、投资政策声明（IPS）、资产配置记忆，再判意图（记录/诊断/配置/研究/交易/复盘/规则）、选流程档位（轻/中/重），最后调度 26 个专职子 Agent 各司其职——从现金流安全垫、配置对齐，到个股 18 步基本面研究、五套交易系统、宏观五框架、量化仓位（Kelly/ATR）、反方审查、交易纪律闸门，全部走完才允许给出建议。

**任何交易建议必须通过五道闸门**：资金属性 → 家庭安全 → 风险桶 → 标的估值 → 执行行为。**任何分析必须使用实时数据**并标注数据时间，金融数据用内置脚本做 Decimal 精确验算，禁止 AI 心算。

### 首次使用（自动引导，约 1 小时）

安装后第一次对话，SKILL.md 的 **First-Run Gate** 会自动检测 `config/家庭资产.md` 是否还是示例（含占位符），未配置前不会给任何金额级建议，只会引导你完成配置：

1. **必配**：`config/家庭资产.md`（真实资产表）、`config/家庭财务宪法.md`（重算安全垫三档）
2. **应配**：`config/投资政策声明IPS.md`、`config/资产配置记忆.md`（目标配置表）
3. **开箱即用**：决策检查清单、交易纪律、管理工作流

详细流程见 `config/README.md`（带勾选清单）。配置完成后闸门永久关闭，进入正常使用。

安装后在对话中直接说「分析一下腾讯」「我的组合怎么样」「我想买 XX」即可触发。

## 详细介绍

### 这是什么

Family Investment Manager 起源于作者自己的真实需求：个人投资者（产品经理背景）管理家庭财务时，AI 助手经常给出「听起来有道理但没有执行含义」的建议。这个 Skill 把所有踩过的坑（用生活费补仓、动态/静态 PE 口径错误导致估值结论翻倍、跳过核心分析凭记忆写简化版等）固化成了规则和闸门。

它不是一个「会分析股票的提示词」，而是一个**多 Agent 编排系统**：

- **编排层**（`SKILL.md`）：判意图、选档位、路由子 Agent、控制异常路径、强制执行数据新鲜度闸门
- **调度层**（`references/Agent索引.md`）：意图 → 子 Agent 的完整路由表，标注 🔴必读/🟡推荐/🟢按需
- **26 个专业子 Agent**（`references/*.md`）：每个是一个独立工作流，带步骤、检查表、失败模式
- **4 份投资方法论**（`references/methodologies/`）：价值投资与基本面研究、估值与安全边际、多流派投资分析、行业研究与主题投资
- **9 套报告模板**（`templates/`）：公司分析、公司记忆、操作记录、投资决策 Memo、交易复盘、风险桶检查等
- **家庭基准配置**（`config/`）：宪法、资产表、IPS、检查清单、配置记忆——所有决策的锚点
- **验算工具**（`scripts/financial_rigor.py`）：所有金额/估值计算用 Decimal 精确验算，禁止 AI 心算
- **归档链路**：每次分析的结论会落到你的知识库——报告进 `{你的投资库}/` 对应目录，结论更新进公司记忆/配置记忆，操作写进操作记录总表（详见下文「输出与归档链路」）

### 家庭基准（config/）——为什么这是核心

大多数投资 Skill 只教「怎么分析标的」，本 Skill 先教你「你的家庭边界在哪」：

| 文件 | 作用 | 状态 |
|------|------|------|
| `config/家庭财务宪法.md` | 最高规则：安全垫三档、10 条永久禁止、风险桶纪律 | 示例，按家庭情况调整 |
| `config/家庭资产.md` | 家庭资产负债表（现金/投资/房产/车辆/负债） | ⚠️ 脱敏示例，请填入真实数据 |
| `config/投资政策声明IPS.md` | 收益目标、回撤纪律、资产分层、再平衡规则 | 示例，按家庭情况调整 |
| `config/家庭财务决策检查清单.md` | 输出前最后一道闸门，逐项检查 | 开箱即用 |
| `config/交易纪律与行为纠偏规则.md` | 坏习惯映射表 + 五道闸门 | 开箱即用 |
| `config/家庭财务管理工作流.md` | 判断顺序、流程档位、数据获取规则 | 开箱即用 |
| `config/资产配置记忆.md` | 配置目标、偏离度、执行状态（持续更新） | ⚠️ 脱敏示例，请填入真实数据 |

> 资产表超过 14 天会提示，超过 30 天 Skill 会拒绝给金额级建议——这不是 bug，是设计。

### 📡 数据源（自动获取，零配置）

运行时**不需要你配置任何数据源**。Skill 自动执行数据拉取：优先用 Python 库（AKShare / yfinance），本机未安装时自动降级到**零依赖 HTTP 接口**（腾讯 qt / 东方财富），全程无感。

| 数据 | 首选（自动） | 备用（自动降级） | 链接 |
|------|------|------|------|
| A 股行情/PE | 腾讯 qt（HTTP，零依赖） | AKShare | [腾讯 qt](http://qt.gtimg.cn/q=) · [AKShare](https://github.com/akfamily/akshare) |
| A 股财务 | AKShare | 网页搜索 | [AKShare](https://github.com/akfamily/akshare) |
| 基金/ETF | AKShare / ttskill | 天天基金网页 | [AKShare](https://github.com/akfamily/akshare) · [天天基金](https://fund.eastmoney.com) |
| 港美股 | yfinance | Yahoo Finance 网页 | [yfinance](https://github.com/ranaroussi/yfinance) · [Yahoo Finance](https://finance.yahoo.com) |
| 宏观 | AKShare `macro_*` | 东方财富 datacenter | [AKShare](https://github.com/akfamily/akshare) · [东方财富数据中心](https://data.eastmoney.com) |
| 重大事件（FOMC/政治局） | 网页搜索 | — | — |

### 🎬 示例场景（端到端走查）

**示例 1：家庭资产诊断 —— 你说「我的组合怎么样？」**

```
① 判意图 = 诊断（档位：中）
② 读 config/ 基准：宪法 + 家庭资产 + 检查清单
③ 08 现金流与安全垫 → 现金是否 ≥ 舒适线？（不足 → 先补现金，不聊配置）
④ 16 家庭资产负债表 → 资产结构全景 + 数据新鲜度校验
⑤ 02 大类资产配置 → 与 IPS 目标比偏离度（哪个桶超配/欠配）
⑥ 13 压力测试 → 权益 -30% 扛不扛得住？
└─ 输出：诊断报告（先结论再证据）+ 落盘 {你的投资库}/定期复盘/ + 更新 config/资产配置记忆.md
```

**示例 2：个股研究 —— 你说「分析一下腾讯」**

```
① 判意图 = 研究-个股（档位：中）
② 🔴 read_file 03 基本面研究 → 18 步完整走（AI 偏见自查 → 生意 → 财务 → 护城河 → 管理层 → 估值）
③ 🟡 05 技术与市场行为 → 当前趋势/供需/止损位置（只服务执行节奏）
④ 🟡 11 宏观与周期 → 周期位置 + 风险资产仓位上限
⑤ 🟡 04 估值与安全边际 → 深度估值（DCF/分部）+ 安全边际 + 失效条件
⑥ 数据交叉验证：PE 必须 ≥2 源（BYD 教训：动态/静态 PE 差一倍）
└─ 输出：四件套投资分析报告 + 更新 {你的记忆库}/公司研究/腾讯-公司记忆.md
```

**示例 3：交易决策 —— 你说「我想买腾讯」**

```
① 判意图 = 交易（档位：重）→ 五道闸门全过才能给建议
② 闸门 1-2：08 资金属性 + 家庭安全（是长期投资资金？现金 ≥ 舒适线？）
③ 闸门 3：02 风险桶（腾讯属于哪个桶？超配了吗？）
④ 闸门 4：03 基本面完整 18 步 + 07 反方审查（先找不买的理由）
⑤ 闸门 5：14 交易纪律（检查表 + 24h 冷静期 + 行为评分）
⑥ 06 风险与仓位 → Kelly/ATR 算出这笔买多少
└─ 输出：投资决策 Memo + 写操作记录 + 报告落盘 + 更新公司记忆
```

**示例 4：基金穿透 —— 你说「帮我看看这只基金」**

```
① 判意图 = 研究-基金（档位：中）
② 🔴 read_file 15 基金与产品穿透
③ 策略/风格/业绩归因 → 经理 → 费率 → 底层持仓
④ 组合重叠度检查：和已有持仓重叠 >40% → 报警（伪分散）
└─ 输出：基金分析报告 + 落盘 {你的投资库}/基金分析/
```

**示例 5：行业精选 —— 你说「AI 算力有哪些值得买的」**

```
① 判意图 = 研究-行业（精选）
② 17 行业研究 8 步 → 产业链全景
③ 18 行业漏斗 → 全市场 → ≤10 候选 → 3 精选
④ 19 去劣筛选 → 7 硬指标排除财务造假/高质押
⑤ 20 供应链瓶颈猎手 → 哪一环先不够用？
└─ 输出：行业漏斗报告 + 3 个候选标的清单
```

> 所有示例的共同点：**先家庭闸门，再标的研究；先反方，再结论；先落盘，才算完。**

### 输出与归档链路（落盘规则）

> 完整规则见 `config/家庭财务管理工作流.md` 第 10 节「归档规则」。核心原则：**分析做完 = 报告落盘 + 记忆更新，缺一个 = 没做完。**
> `{你的投资库}` / `{你的记忆库}` 是通用占位符：指你本地知识库中的投资记录目录和公司记忆目录（Obsidian 等任意结构均可，按你实际目录映射）。

**投资类产出 → `{你的投资库}/`**

| 产出 | 落盘位置 | 命名规则 |
|------|------|------|

| 公司记忆（canonical） | `{你的记忆库}/公司研究/` | `{公司名}-公司记忆.md`，每次分析后更新，不新建 |
