**家庭投资管理（Family Investment Manager）** 是一个 Agent Skill（适用于 Claude Code / Codex / VS Code Copilot 等 AI 编程助手）：以**家庭财务基准**（资产表、安全垫、IPS、风险桶）为锚点，用 1 个编排层 + 26 个专业子 Agent + 4 份投资方法论 + 9 套报告模板 + 1 个金融验算工具，把每一次投资决策变成一条有纪律、可复盘、有闸门的完整流水线——而不是给你一个没有执行含义的市场观点。

> ⚠️ **任何交易建议必须通过五道闸门**：资金属性 → 家庭安全 → 风险桶 → 标的估值 → 执行行为。它不承诺收益、不构成投资建议。

## 能力总结

Family Investment Manager 是一个面向个人投资者的家庭投资管理 Skill。它以「家庭财务基准优先于市场观点」为核心设计：先读你的家庭资产表、财务宪法（安全垫）、投资政策声明（IPS）、资产配置记忆，再判意图（记录/诊断/配置/研究/交易/复盘/规则）、选流程档位（轻/中/重），最后调度 26 个专职子 Agent 各司其职——从现金流安全垫、配置对齐，到个股 18 步基本面研究、五套交易系统、宏观五框架、量化仓位（Kelly/ATR）、反方审查、交易纪律闸门，全部走完才允许给出建议。

**任何交易建议必须通过五道闸门**：资金属性 → 家庭安全 → 风险桶 → 标的估值 → 执行行为。**任何分析必须使用实时数据**并标注数据时间，金融数据用内置脚本做 Decimal 精确验算，禁止 AI 心算。

## 安装

```bash
# 方式一：全局安装（Claude Code / Codex / VS Code Copilot 通用，推荐）
git clone https://github.com/yeyulangzi/family-investment-manager.git
mkdir -p ~/.agents/skills
cp -R family-investment-manager ~/.agents/skills/

# 方式二：项目级安装
cp -R family-investment-manager /path/to/your/project/.claude/skills/
```

### 首次使用（自动引导，约 1 小时）

安装后第一次对话，SKILL.md 的 **First-Run Gate** 会自动检测 `config/家庭资产.md` 是否还是示例（含占位符），未配置前不会给任何金额级建议，只会引导你完成配置：

1. **必配**：`config/家庭资产.md`（真实资产表）、`config/家庭财务宪法.md`（重算安全垫三档）
2. **应配**：`config/投资政策声明IPS.md`、`config/资产配置记忆.md`（目标配置表）
3. **开箱即用**：决策检查清单、交易纪律、管理工作流

详细流程见 `config/README.md`（带勾选清单）。配置完成后闸门永久关闭，进入正常使用。

安装后在对话中直接说「分析一下腾讯」「我的组合怎么样」「我想买 XX」即可触发。

## 详细介绍

### 这是什么

Family Investment Manager 起源于作者自己的真实需求：个人投资者（产品经理背景）管理家庭财务时，AI 助手经常给出「听起来有道理但没有执行含义」的建议。这个 Skill 把所有踩过的坑（用生活费补仓、动态/静态 PE 口径错误导致估值结论翻倍、跳过核心分析凭记忆写简化版等）固化成了规则和闸门。

它不是一个「会分析股票的提示词」，而是一个**多 Agent 编排系统**：

- **编排层**（`SKILL.md`）：判意图、选档位、路由子 Agent、控制异常路径、强制执行数据新鲜度闸门
- **调度层**（`references/Agent索引.md`）：意图 → 子 Agent 的完整路由表，标注 🔴必读/🟡推荐/🟢按需
- **26 个专业子 Agent**（`references/*.md`）：每个是一个独立工作流，带步骤、检查表、失败模式
- **4 份投资方法论**（`references/methodologies/`）：价值投资与基本面研究、估值与安全边际、多流派投资分析、行业研究与主题投资
- **9 套报告模板**（`templates/`）：公司分析、公司记忆、操作记录、投资决策 Memo、交易复盘、风险桶检查等
- **家庭基准配置**（`config/`）：宪法、资产表、IPS、检查清单、配置记忆——所有决策的锚点
- **验算工具**（`scripts/financial_rigor.py`）：所有金额/估值计算用 Decimal 精确验算，禁止 AI 心算

### 家庭基准（config/）——为什么这是核心

大多数投资 Skill 只教「怎么分析标的」，本 Skill 先教你「你的家庭边界在哪」：

| 文件 | 作用 | 状态 |
|------|------|------|
| `config/家庭财务宪法.md` | 最高规则：安全垫三档、10 条永久禁止、风险桶纪律 | 示例，按家庭情况调整 |
| `config/家庭资产.md` | 家庭资产负债表（现金/投资/房产/车辆/负债） | ⚠️ 脱敏示例，请填入真实数据 |
| `config/投资政策声明IPS.md` | 收益目标、回撤纪律、资产分层、再平衡规则 | 示例，按家庭情况调整 |
| `config/家庭财务决策检查清单.md` | 输出前最后一道闸门，逐项检查 | 开箱即用 |
| `config/交易纪律与行为纠偏规则.md` | 坏习惯映射表 + 五道闸门 | 开箱即用 |
| `config/家庭财务管理工作流.md` | 判断顺序、流程档位、数据获取规则 | 开箱即用 |
| `config/资产配置记忆.md` | 配置目标、偏离度、执行状态（持续更新） | ⚠️ 脱敏示例，请填入真实数据 |

> 资产表超过 14 天会提示，超过 30 天 Skill 会拒绝给金额级建议——这不是 bug，是设计。

### 使用场景

| 场景 | 说明 |
|------|------|
| 家庭资产诊断 | 「我的组合怎么样」「看看持仓」→ 现金流安全垫检查 → 配置偏离度诊断 |
| 大类资产配置 | 「新增资金怎么放」「要不要再平衡」→ IPS 对齐 + 风险桶检查 |
| 个股/公司研究 | 「分析一下腾讯」→ 18 步基本面 + 技术面 + 宏观 + 深度估值四件套 |
| 财报精读 | 财报发布后 → 读一手资料，不读二手研报 |
| 行业研究 | 全景（8 步）→ 精选（行业漏斗 + 去劣筛选）→ 供应链瓶颈猎手 |
| 基金/ETF 穿透 | 策略/风格/业绩归因/经理/费率/持仓重叠度检查 |
| 交易决策 | 五道闸门全过 → 反方审查 → 纪律检查 → 量化仓位 |
| 复盘 | 操作记录 → 原决策对比 → 是运气还是能力 |
| 股价异动 | 10 分钟快速归因，避免恐慌操作 |

| 文件 | 内容 |

**9 套模板**（`templates/`）：公司分析报告、公司记忆文件、操作记录、投资决策 Memo、交易前检查清单、交易复盘、家庭资产配置分析、月度家庭财务复盘、风险桶检查

**验算脚本**（`scripts/financial_rigor.py`，基于 Decimal 精确计算）

| 命令 | 能力 |
|------|------|
| `verify-market-cap` | 市值验算：股价 × 股本 → 与报告值对比 |
| `verify-valuation` | 估值指标验算：PE / PB / FCF Yield / 股息率 |
| `cross-validate` | 多源交叉验证：N 个来源同一数据的自动比对 |
| `three-scenario` | 三情景估值：乐观 / 基准 / 悲观 |
| `calc` | 通用精确计算 |
| `benford` | Benford 定律检测（数据造假/口径异常筛查） |

**五大纪律闸门**（交易类必过）

1. 资金属性（不能用生活费）→ 2. 家庭安全（安全垫底线）→ 3. 风险桶（配置限额）→ 4. 标的估值（完整分析）→ 5. 执行行为（冷静期 + 纪律检查）

### 边界与免责声明

- 本 Skill 不承诺收益，不构成投资建议；所有输出仅供个人决策参考，最终投资责任由使用者承担
- 交易纪律硬规则：数据不交叉验证不下结论、安全垫不足不给买入建议、技术面不单独构成投资理由
- 数据来源建议：A 股行情（腾讯 qt / AKShare）、港美股（yfinance）、宏观（AKShare / 东方财富）
- `config/家庭资产.md`、`config/资产配置记忆.md` 含真实家庭财务数据，**不要提交到公开仓库**（.gitignore 已排除）
