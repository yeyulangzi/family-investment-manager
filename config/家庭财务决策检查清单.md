# 家庭财务决策检查清单

> 执行入口：`SKILL.md`（本 Skill 编排层，意图分流 → 子 Agent 路由）。
> 本清单是输出前的最后一道闸门，所有决策必须逐项通过。

每次正式输出家庭财务或投资建议前，必须逐项检查。

## 1. 数据检查

> 数据获取必须遵守 `家庭财务管理工作流.md` 第 2.4 节「数据获取规则」：优先 AKShare→ttskill→futuapi，关键数据双源交叉验证，PE 优先静态/TTM。

- [ ] 是否读取最新 `{你的工作区}/家庭财务/家庭资产.md`？
- [ ] 是否读取 `{你的工作区}/家庭财务/资产配置记忆.md`？
- [ ] 是否确认资产数据日期？
- [ ] 是否区分人民币、港币、美元？
- [ ] 是否标记缺失数据？
- [ ] 关键数字是否来自至少 2 个独立来源？（基金净值：ttskill + 天天基金网页；股票：东方财富 + 巨潮等）
- [ ] 所有金额是否标注了数据日期？（不能用一周前的市值做今天的判断）
- [ ] PE 是否优先使用静态 PE 或 TTM PE？（禁止单用动态 PE）
- [ ] "估算"和"实测"是否明确区分？
- [ ] 如果某项关键数据无法交叉验证，是否降级为"低置信度"并标注？

## 1.5. 信息丰富度检查（新增）

- [ ] 本次研究的整体信息丰富度是否评了 A/B/C 级？
- [ ] 如果 C 级，是否附了"需要一手验证的问题清单"？
- [ ] 是否区分了"AI 分析置信度"和"投资确定性"？（资料多≠判断对）

## 2. 家庭安全检查

- [ ] 现金/类现金是否达到目标？
- [ ] 是否存在未来 6-12 个月收入不确定？
- [ ] 是否存在创业、教育、医疗、房产等大额支出？
- [ ] 是否动用了应急金？（按家庭实际情况确认：创业备用金是否已释放、是否暂不考虑创业）
- [ ] 是否考虑保险和负债约束？

## 3. 资产配置检查

- [ ] 是否明确资金属于短期资金还是长期投资资金？
- [ ] 是否检查大类资产目标比例？
- [ ] 是否检查资产类别偏离？
- [ ] 是否检查同一风险桶？
- [ ] 是否检查基金和个股重叠？

## 4. 投资标的检查

- [ ] 公司/基金/资产逻辑是否成立？
- [ ] 是否有估值或性价比判断？
- [ ] 是否有安全边际？
- [ ] 是否有替代资产比较？
- [ ] 是否写了失效条件？

## 5. 宏观与黑天鹅检查

- [ ] 是否检查利率、通胀、汇率、流动性和政策环境？
- [ ] 是否做压力测试？
- [ ] 是否考虑权益大跌、中国互联网大跌、收入中断、房价下跌？
- [ ] 压力测试是否影响仓位上限？

## 6. 行为金融检查

- [ ] 是否存在追涨？
- [ ] 是否存在下跌补仓冲动？
- [ ] 是否存在亏损厌恶？
- [ ] 是否存在锚定成本或历史高点？
- [ ] 是否存在熟悉度偏误？
- [ ] 是否因为已持有而找理由？

## 7. 输出检查

- [ ] 是否给出明确动作？
- [ ] 是否写明不做什么？
- [ ] 是否写明金额、顺序、分批节奏？
- [ ] 是否写明触发条件？
- [ ] 是否写明复盘日期？
- [ ] 是否写入对应记忆或报告？

只要关键项未通过，就不能输出强执行建议。
