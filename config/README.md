# config/ — 首次使用配置流程（第 0 步）

> 本 Skill 的所有决策都以「家庭财务基准」为锚点，而不是以市场观点为锚点。
> **SKILL.md 的 First-Run Gate 会自动检测你是否已配置**（检查 `家庭资产.md` 是否还有占位符），未配置前不会给任何金额级建议。

## 配置流程（按顺序，一次一个文件）

### 🔴 第 1 步：家庭资产（必配，10 分钟）

打开 `家庭资产.md`，照示例结构替换为你的真实数据：

- [ ] 资产负债表：流动资产 / 投资资产 / 固定资产 / 负债 / 净资产
- [ ] 金融资产底层分类：现金 / 固收 / 权益 / 黄金
- [ ] 更新日期和统计口径说明（标注数据来源）

> 完成后确认：文件中不再出现 `¥XXX`、`{日期}` 等占位符 → First-Run Gate 自动通过。

### 🔴 第 2 步：家庭财务宪法（必配，15 分钟）

打开 `家庭财务宪法.md`，重算你自己的三档安全垫：

- [ ] 硬底线 = 12 个月固定支出 + 收入空窗缓冲 + 医疗/应急缓冲
- [ ] 执行舒适线 = 你当前阶段的安全感线
- [ ] 安全垫执行容器拆桶（银行卡 / 货币基金 / 次级缓冲 / 低波债）
- [ ] 检查 10 条永久禁止事项是否符合你的家庭情况，可增删

### 🟡 第 3 步：投资政策声明 IPS（应配，20 分钟）

打开 `投资政策声明IPS.md`：

- [ ] 长期目标收益（示例 10%，按你的风险偏好定）
- [ ] 回撤纪律口径（预警线 / 硬上限 / 权益压力测试）
- [ ] 家庭约束（收入预期 / 月支出 / 大额资金需求 / 负债 / 保障）
- [ ] 资产分层：不投资资金（安全垫容器）+ 长期投资资金（大类目标比例）

### 🟡 第 4 步：资产配置记忆（应配，10 分钟）

打开 `资产配置记忆.md`：

- [ ] 建立目标配置表（类别 / 目标比例 / 目标金额 / 当前 / 偏离）
- [ ] 写下当前核心矛盾（如：权益缺口 vs 现金超配）

### 🟢 第 5 步：开箱即用（无需修改）

以下文件已可直接使用：

- `家庭财务决策检查清单.md` — 输出前最后一道闸门
- `交易纪律与行为纠偏规则.md` — 坏习惯映射表 + 五道闸门
- `家庭财务管理工作流.md` — 判断顺序、流程档位、数据获取规则

## 三个最容易踩的坑

1. **资产表必须新鲜**：超过 14 天提示，超过 30 天 Skill 会拒绝给金额级建议——这不是 bug，是设计。
2. **安全垫数字是示例**：140 万舒适线 / 100 万硬底线来自原作者的辞职缓冲场景，请按你的「12 个月固定支出 + 收入空窗缓冲 + 应急」重新测算。
3. **不要提交真实资产数据**：`.gitignore` 已默认排除 `家庭资产.md` 和 `资产配置记忆.md`，请保持。
