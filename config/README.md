# config/ — 家庭基准配置（首次使用必读）

本 Skill 的所有决策都以「家庭财务基准」为锚点，而不是以市场观点为锚点。这些基准文件**必须由你根据自家情况创建**，Skill 才能正确运行。

## 文件清单

| 文件 | 作用 | 是否含隐私数据 |
|------|------|------|
| `家庭资产.md` | 家庭资产负债表（现金/投资/房产/车辆/负债） | ⚠️ 含真实金额，**不要提交到公开仓库** |
| `家庭财务宪法.md` | 最高规则：安全垫、永久禁止事项、风险桶纪律 | 金额为示例，按需调整 |
| `家庭财务决策检查清单.md` | 输出前最后一道闸门，逐项检查 | 无 |
| `投资政策声明IPS.md` | 投资政策：收益目标、回撤纪律、资产分层 | 金额为示例，按需调整 |
| `交易纪律与行为纠偏规则.md` | 坏习惯映射表 + 五道闸门 | 无 |
| `家庭财务管理工作流.md` | 判断顺序、流程档位、数据获取规则 | 无 |
| `资产配置记忆.md` | 配置目标、偏离度、执行状态（会持续更新） | ⚠️ 含真实金额，**不要提交到公开仓库** |

## 建议目录结构

```
config/
├── README.md                  ← 本文件
├── 家庭资产.md                ← 你创建（脱敏示例见本文件）
├── 家庭财务宪法.md            ← 示例，按家庭情况调整
├── 家庭财务决策检查清单.md    ← 开箱即用
├── 投资政策声明IPS.md         ← 示例，按家庭情况调整
├── 交易纪律与行为纠偏规则.md  ← 开箱即用
├── 家庭财务管理工作流.md      ← 开箱即用
└── 资产配置记忆.md            ← 你创建（脱敏示例见本文件）
```

## 三个最容易踩的坑

1. **资产表必须新鲜**：超过 14 天提示，超过 30 天 Skill 会拒绝给金额级建议——这不是 bug，是设计。
2. **安全垫数字是示例**：140 万舒适线 / 100 万硬底线来自原作者的辞职缓冲场景，请按你的「12 个月固定支出 + 收入空窗缓冲 + 应急」重新测算。
3. **不要提交真实资产数据**：`.gitignore` 已默认排除，请保持。
