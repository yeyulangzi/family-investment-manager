# config/ — Skill 通用文件 + 个性化数据模板

> `config/` 只放两类东西：**Skill 通用定义**（方法论/工作流/规则，开箱即用）+ **个性化数据模板**（首次使用时自动复制到你的工作区）。
> 你的**真实家庭数据不放在这里**，放在 `{你的工作区}/家庭财务/`（由 Skill 自动初始化）。

## 两类文件说明

### 🟢 A 类：Skill 通用文件（留在 config/，开箱即用）

| 文件 | 作用 |
|------|------|
| `家庭财务管理工作流.md` | 判断顺序、流程档位、数据获取规则——Skill 的行为定义 |
| `家庭财务决策检查清单.md` | 输出前最后一道闸门，逐项检查 |
| `交易纪律与行为纠偏规则.md` | 坏习惯映射表 + 五道闸门 |

这些是 Skill 的一部分，升级 Skill 时会被更新，**不需要用户修改**。

### 🔴 B 类：个性化数据模板（首次自动复制到工作区）

| 模板 | 初始化目标 | 用户需要做什么 |
|------|------|------|
| `家庭资产.md` | `{你的工作区}/家庭财务/家庭资产.md` | 填真实资产表 |
| `家庭财务宪法.md` | `{你的工作区}/家庭财务/家庭财务宪法.md` | 重算安全垫三档 |
| `投资政策声明IPS.md` | `{你的工作区}/家庭财务/投资政策声明IPS.md` | 写收益目标/回撤纪律/资产分层 |
| `资产配置记忆.md` | `{你的工作区}/家庭财务/资产配置记忆.md` | 建目标配置表（持续更新） |

这些是**模板不是数据**：保持原样，Skill 在首次使用时自动复制到你的工作区，你在**工作区副本**里填写。升级 Skill 不会覆盖工作区里的真实数据。

## 初始化流程（Skill 自动执行，用户无需手动）

1. 首次使用时，SKILL.md 的 First-Run Gate 检查 `{你的工作区}/家庭财务/家庭资产.md` 是否存在
2. **不存在** → Skill 自动创建目录 + 从 config/ 复制 4 个模板（像产报告一样创建文件）→ 引导你填写
3. **存在但仍是模板**（含 `¥XXX` 占位符）→ 引导你填写
4. **存在且已填写** → 闸门永久关闭

## 填写流程（按顺序，一次一个文件）

### 🔴 第 1 步：家庭资产（必填，10 分钟）

打开工作区的 `家庭资产.md`，照模板结构替换为你的真实数据：

- [ ] 资产负债表：流动资产 / 投资资产 / 固定资产 / 负债 / 净资产
- [ ] 金融资产底层分类：现金 / 固收 / 权益 / 黄金
- [ ] 更新日期和统计口径说明（标注数据来源）

> 完成后确认：文件中不再出现 `¥XXX`、`{日期}` 等占位符 → First-Run Gate 自动通过。

### 🔴 第 2 步：家庭财务宪法（必填，15 分钟）

打开工作区的 `家庭财务宪法.md`，重算你自己的三档安全垫：

- [ ] 硬底线 = 12 个月固定支出 + 收入空窗缓冲 + 医疗/应急缓冲
- [ ] 执行舒适线 = 你当前阶段的安全感线
- [ ] 安全垫执行容器拆桶（银行卡 / 货币基金 / 次级缓冲 / 低波债）
- [ ] 检查 10 条永久禁止事项是否符合你的家庭情况，可增删

### 🟡 第 3 步：投资政策声明 IPS（应填，20 分钟）

打开工作区的 `投资政策声明IPS.md`：

- [ ] 长期目标收益（示例 10%，按你的风险偏好定）
- [ ] 回撤纪律口径（预警线 / 硬上限 / 权益压力测试）
- [ ] 家庭约束（收入预期 / 月支出 / 大额资金需求 / 负债 / 保障）
- [ ] 资产分层：不投资资金（安全垫容器）+ 长期投资资金（大类目标比例）

### 🟡 第 4 步：资产配置记忆（应填，10 分钟）

打开工作区的 `资产配置记忆.md`：

- [ ] 建立目标配置表（类别 / 目标比例 / 目标金额 / 当前 / 偏离）
- [ ] 写下当前核心矛盾（如：权益缺口 vs 现金超配）

## 三个最容易踩的坑

1. **资产表必须新鲜**：超过 14 天提示，超过 30 天 Skill 会拒绝给金额级建议——这不是 bug，是设计。
2. **安全垫数字是示例**：模板里的 140 万舒适线 / 100 万硬底线来自原作者的辞职缓冲场景，请按你的「12 个月固定支出 + 收入空窗缓冲 + 应急」重新测算。
3. **只改工作区副本，不改 config/ 模板**：config/ 里的模板保持原样，升级 Skill 时才不会被覆盖冲突；工作区数据不受 Skill 升级影响。
