# 交易纪律与行为纠偏规则

## 1. 目标

这份规则的目标不是提高短期胜率，而是降低坏交易习惯对家庭资产的伤害。

重点纠正：

- 追涨 FOMO。
- 大跌冲动补仓。
- 频繁交易。
- 亏损不愿承认错误。
- 用新闻替代研究。
- 因熟悉公司而高估确定性。
- 单一风险桶越买越多。
- 临时改变原计划。

## 2. 坏习惯映射表

| 坏习惯 | 识别信号 | 系统约束 |
| --- | --- | --- |
| 追涨 FOMO | “再不上车就错过了” | 超过计划买入区间自动禁止买入，至少冷静 24 小时 |
| 跌了想补仓 | “便宜了再买一点摊成本” | 先判断逻辑是否失效，风险桶有空间才允许 |
| 频繁交易 | 一周内多次临时操作 | 月度交易次数上限，超限只能复盘 |
| 亏损不认错 | 用长期主义掩盖失效 | 触发失效条件必须重新审查 |
| 新闻驱动 | 看一条新闻就想操作 | 新闻只能触发研究，不能直接触发交易 |
| 熟悉度偏误 | 因常用产品而重仓 | 必须写反方观点和替代资产比较 |
| 主题堆积 | 每个主题都小买一点 | 主题基金默认清理或小仓，不能做核心 |
| 临时改计划 | 盘中突然改变动作 | 重大调整必须冷静 24 小时并写新 memo |

## 3. 交易闸门

任何买入、卖出、加仓、减仓前，必须通过五道闸门：

### 闸门 1：资金属性

- 这笔钱属于应急金、短期资金，还是长期投资资金？（按家庭实际情况确认创业备用金状态）
- 如果不是长期投资资金，禁止买入高波动资产。

### 闸门 2：家庭安全

- 操作后现金/类现金是否仍达到宪法规定的执行舒适线（示例：RMB 1,400,000，按 config/家庭财务宪法.md 实际值）？
- 未来 6-12 个月是否会有收入或支出压力？
- 如果降低安全垫，禁止执行。

### 闸门 3：风险桶

- 标的属于哪个风险桶？
- 风险桶当前是否超配？
- 如果超配，新增同类资产禁止执行。

### 闸门 4：标的和估值

- 标的逻辑是否成立？
- 当前估值是否有安全边际？
- 是否有替代资产更简单、更分散、更低成本？

### 闸门 5：执行和行为

- 是否处在冷静期？
- 是否因涨跌、新闻、焦虑或不甘心而交易？
- 是否写清失效条件和复盘日期？

五道闸门全部通过，才允许执行。

## 4. 冷静期

| 触发条件 | 冷静期 |
| --- | --- |
| 单笔新增权益超过长期投资资金 2% | 24 小时 |
| 单一标的加仓超过原仓位 20% | 24 小时 |
| 因上涨想追买 | 24 小时，且重新检查估值 |
| 因下跌想补仓 | 收盘后复盘，不能盘中冲动执行 |
| 连续两笔交易亏损 | 7 天禁手 |
| 用户情绪明显焦虑或急于翻本 | 7 天禁手 |
| 财报、政策、宏观事件前临时加仓 | 等事件落地 |

收入空窗阶段，连续亏损或情绪交易的禁手期从 7 天提高到 14 天；新增主题基金、新个股和高波动卫星默认否决。

冷静期内只能做研究、记录和复盘，不能新增风险资产。

## 5. 交易次数和频率

- 每月主动交易原则上不超过 4 次。
- 超过 4 次后，当月只能执行预先写好的再平衡计划，不能临时交易。
- 基金定投或已写明的分批计划不计为冲动交易，但必须在计划内。

## 6. 交易前必须填写

每次交易前必须记录：

- 日期。
- 标的。
- 买/卖/加/减。
- 金额或数量。
- 价格区间。
- 资金来源。
- 所属风险桶。
- 操作理由。
- 如果错了，最可能错在哪里。
- 失效条件。
- 复盘日期。
- 当前情绪状态。

## 7. 交易后复盘评分

复盘时不只看赚亏，分两类评分。

### 7.1 决策质量分

| 项目 | 分值 |
| --- | ---: |
| 是否符合家庭财务宪法 | 0-2 |
| 是否符合 IPS | 0-2 |
| 是否通过风险桶检查 | 0-2 |
| 是否有估值和安全边际 | 0-2 |
| 是否写了失效条件 | 0-1 |
| 是否按计划执行 | 0-1 |

满分 10 分。低于 7 分，说明这次交易流程质量不足。

### 7.2 结果分

| 项目 | 分值 |
| --- | ---: |
| 收益是否符合预期 | 0-3 |
| 回撤是否在预期内 | 0-3 |
| 原假设是否被验证 | 0-2 |
| 是否暴露新风险 | 0-2 |

结果分不能替代决策质量分。

## 8. 标准拒绝句式

当操作不符合纪律时，系统必须明确拒绝：

```text
不建议执行。
违反规则：X。
当前更合适的动作：Y。
重新开放交易的条件：Z。
```

不能为了迎合用户情绪而软化成“也可以少买一点”。
