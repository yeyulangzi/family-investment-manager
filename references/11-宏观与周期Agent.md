# 11-宏观与周期Agent — 宏观状态诊断与周期定位

> 宏观不预测股价。宏观回答三个问题：
> ① 当前周期位置在哪？→ 决定风险资产仓位上限
> ② 各类资产的相对排序？→ 决定配置倾斜方向
> ③ 什么信号出现时，上述判断需要推翻？→ 决定退出条件

---

## 一、框架总览：三层时间结构

任何单一框架都有盲区。真正有用的宏观分析是**多框架叠加，找交集，暴露矛盾**。

```
长期（5-50 年）：Dalio 债务周期 → 定大方向：加杠杆 / 去杠杆 / 漂亮去杠杆？
  ↓
中期（1-5 年）：Pring 六阶段 + ML 时钟 → 定周期位置：哪个阶段？
  ↓                              ↓
短期（1-12 月）：流动性 + 跨市场（Murphy）→ 定执行节奏 + 交叉验证
  ↓
行为校准：Marks  pendulum → 当前市场在贪婪还是恐惧的什么位置？
```

**关键原则**：越长期的框架越慢、越模糊，但越重要。短期的噪音可以错过，长期的方向不能站错队。

## 二、长期框架：Dalio 债务周期

### 2.1 核心逻辑

Ray Dalio 的核心洞察：经济运行由三个力驱动：
1. **生产率增长**（最慢，最稳定，长期向上）
2. **短期债务周期**（5-8 年，央行可控）
3. **长期债务周期**（50-75 年，债务/GDP 到极限后的去杠杆）

### 2.2 判断当前处于长期债务周期的哪个阶段

关键不是预测，是识别特征：

| 阶段 | 特征 | 历史案例 |
|------|------|------|
| **加杠杆上半场** | 债务增速 < 收入增速，债务用于生产性投资 | 中国 2001-2012 |
| **加杠杆下半场** | 债务增速 > 收入增速，债务用于消费/投机/填旧债 | 中国 2013-2021 |
| **顶部** | 央行无力再降息（已近零），债务/GDP 高位，资产泡沫 | 日本 1989，美国 2007 |
| **去杠杆** | 债务/GDP 下降，四种方式：债务重组、财政紧缩、财富转移、央行印钞 | — |
| **漂亮去杠杆** | 印钞 + 财政刺激冲销通缩压力，名义 GDP > 利率 | 美国 2008-2016 |
| **丑陋去杠杆** | 印钞失控→恶性通胀，或财政紧缩过头→大萧条 | 1930s 美国，魏玛德国 |

### 2.3 中国当前（2026 年）的债务周期判断框架

```
必看数据点：
  ├─ 中国债务/GDP（BIS 统计，季频）→ 当前约 300%+
  ├─ 居民杠杆率 → 约 64%，已见顶
  ├─ 企业杠杆率 → 约 170%，分化严重（国企高/民企低）
  ├─ 政府杠杆率（显性+隐性）→ 显性低，隐性（城投）是真实压力
  └─ 名义 GDP vs 加权平均利率 → 如果名义 GDP 增速 < 利率，去杠杆压力加大

核心判断逻辑（不是结论，是思考框架）：
  中国不是典型的去杠杆（没有崩盘），也不是典型的加杠杆（信贷冲动减弱）。
  → 更像是「钝刀去杠杆」：用时间换空间，用通胀稀释债务，用结构性政策精准滴灌
  → 对投资的含义：全面牛市概率低（缺信贷驱动），全面崩盘概率也低（政策兜底），结构性行情是常态
```

### 2.4 Dalio 框架的局限

- 债务/GDP 阈值不是机械的——日本 300%+ 也没崩，因为债务是日元本币债
- 中国的外债占比很低（<15%），本币债务的违约风险与外币债务完全不同
- 政策干预可以改变去杠杆的路径——中国有比美国/日本更强的政策工具
- **矛盾提醒**：Dalio 模型预测去杠杆的痛苦调整，但中国的行政力量可以压制尾部风险。两者并存——调整会来，但路径不是自由市场式的。

## 三、中期框架（一）：Pring 六阶段

Martin Pring 的改进：不是 4 个象限，是 6 个阶段。债券市场最早给出信号。

### 3.1 六阶段的识别

Pring 用三个市场的相对运动来划分阶段。逻辑链：**债券先动 → 股票跟进 → 商品最后**。

| 阶段 | 债券 | 股票 | 商品 | 经济含义 | 最优资产 |
|:--:|:--:|:--:|:--:|------|------|
| **一** | ↗ | ↘ | ↘ | 衰退末期，央行宽松，债市已涨 | 债券、防御股 |
| **二** | ↗ | ↗ | ↘ | 复苏初期，股市底部确认 | 股票（周期成长）、债券 |
| **三** | → | ↗ | → | 复苏确认，债市涨势放缓 | 股票（广泛） |
| **四** | ↘ | ↗ | ↗ | 扩张中后期，商品启动 | 商品、价值股 |
| **五** | ↘ | → | ↗ | 过热，债券预示收紧 | 商品、现金 |
| **六** | ↘ | ↘ | → | 收缩，三杀开始 | 现金、债券（等待）|

### 3.2 当前阶段判断方法

不是猜，是逐项对照数据：

```
必看数据点（月度更新）：
  ├─ 债券：中国 10 年期国债收益率趋势（↑/↓/→）+ 信用利差（AA-AAA）
  ├─ 股票：沪深 300 的 26 周均线方向 + 指数从低点涨幅
  └─ 商品：南华商品指数趋势 + CRB 指数

判断规则（机械）：
  债券 3 个月上行 + 股票 3 个月上行 + 商品未确认 → 阶段二
  债券横盘 + 股票上行 + 商品启动 → 阶段三/四
  债券下行 + 股票横盘 + 商品强势上行 → 阶段五
  三者全下行 → 阶段六
  
⚠️ 不用精确到某个阶段——知道大致在哪（早/中/晚期）就够了。
```

### 3.3 Pring vs ML 时钟的矛盾

```
核心差异：
  Pring 用债券价格（利率）做先行指标 → 债券启动 = 阶段一
  ML 时钟用经济增长和通胀同时判断 → 没有先行指标概念

当两者矛盾时（例：Pring 说阶段四 = 股票+商品涨，但 ML 时钟说"滞胀"= 现金最优）：
  → Pring 通常更早捕捉转折（因为有债券领先信号）
  → ML 时钟通常更准确描述"当前这一刻"的状态
  → 实操：如果 Pring 比 ML 早一个阶段 → 减仓但不空仓（Pring 可能对，但也可能假信号）
  → 如果两个框架都指向同一方向 → 可以做仓位决策
```

## 四、中期框架（二）：美林投资时钟

### 4.1 核心逻辑

用两个变量切四象限：**经济增长方向**（OECD 领先指标/PMI） × **通胀方向**（CPI）

| 象限 | 增长 | 通胀 | 最优 | 次优 | 最差 |
|------|:--:|:--:|------|------|------|
| **复苏** | ↑ | ↓ | 股票（周期成长）| 债券 | 现金 |
| **过热** | ↑ | ↑ | 商品 | 股票（价值/周期）| 债券 |
| **滞胀** | ↓ | ↑ | 现金 | 商品 | 股票、债券 |
| **衰退** | ↓ | ↓ | 债券 | 防御股/高股息 | 商品、周期股 |

### 4.2 中国版 ML 时钟的修正

标准 ML 时钟用美国数据，照搬到中国会出错：

```
中国增长指标用：PMI（官方制造业）+ 工业增加值 + 社零
中国通胀指标用：CPI + PPI 平均（PPI 对 A 股利润的影响远大于 CPI）
  → 因为 A 股 60% 市值是工业/金融/周期，PPI 上行 = 利润上行
  → CPI 主要反映猪周期，对股市的指向性不如 PPI

中国特色的阶段特征：
  「过热」在中国很少出现（政策会提前收紧）
  「衰退」通常很短（政策快速宽松）
  最常见的是「复苏→政策收紧→增速放缓→政策放松→复苏」的快速轮动
  → 中国的经济周期更像政策周期，不是自然商业周期
```

### 4.3 时钟失效的三种情况

| 失效模式 | 原因 | 怎么办 |
|------|------|------|
| **外部冲击** | 疫情/战争/油价暴涨 → 增长和通胀同时暴跌，不在任何象限 | 放弃时钟，看政策响应 |
| **政策扭曲** | 央行过度干预导致资产价格与基本面脱钩 | 降时钟权重，看流动性 |
| **结构转型** | 经济换挡期（中国 2012-2016），GDP 增速持续下行但股市有结构性行情 | 不看总量，看行业分化 |

## 五、跨市场验证：Murphy 跨市场分析

Murphy 的核心不是预测，是**交叉验证**。如果 A 市场在涨，但 B 市场没有跟随，说明 A 的涨势可能不可持续。

### 5.1 核心传导链

```
美元 ↗ → 商品 ↘ → 商品货币 ↘ → 新兴市场 ↘ → 全球风险偏好 ↘
美元 ↘ → 商品 ↗ → 商品货币 ↗ → 新兴市场 ↗ → 全球风险偏好 ↗
```

### 5.2 四个关键跨市场关系（每次分析必查）

**关系 1：美元 vs 商品**
```
美元走强（DXY ↑）→ 商品承压（CRB ↓）→ 周期股承压
正常：美元与商品反向
背离：美元涨 + 商品也涨 → 商品基本面极强，或美元涨因避险（需要区分）
```

**关系 2：债券 vs 股票**
```
债券涨（收益率跌）+ 股票跌 → 正常，资金流向避险
债券涨 + 股票涨 → 正常（阶段二），流动性驱动
债券跌（收益率涨）+ 股票涨 → 正常（阶段四/五），经济向好
债券跌 + 股票跌 → 危险——市场在定价什么？（通胀失控？加息恐慌？信用风险？）
  → 这个组合必须深挖原因，不能泛泛解释
```

**关系 3：商品 vs 债券**
```
商品涨 + 债券跌（收益率涨）→ 通胀预期上升 → 央行可能收紧 → 利空长久期
商品跌 + 债券涨（收益率跌）→ 通缩预期 → 利好长久期，利空周期股
```

**关系 4：铜/金比（最重要的单一跨市场比率）**
```
铜金比 ↑ → 增长预期 > 避险需求 → 风险偏好上升 → 利好股票
铜金比 ↓ → 避险 > 增长 → 风险偏好下降 → 债券优于股票
与中国 10 年期国债收益率高度相关 —— 铜金比领先约 3 个月
当前阈值参考：铜金比 < 0.15 = 极度悲观，> 0.25 = 乐观
```

### 5.3 Murphy 与 ML 时钟的矛盾处理

```
经典矛盾场景：
  ML 时钟说"复苏"（增长↑ 通胀↓）→ 利好股票
  但 Murphy 显示：债券收益率在上升 + 美元在走强
  → 矛盾！

处理逻辑：
  债券收益率上升 → 市场在提前定价未来的收紧
  美元走强 → 全球流动性在收缩
  → 这个"复苏"可能很短，或者力度很弱
  → 操作：股票仓位按复苏配置，但不配满（因为跨市场信号在预警）
  → 关注：如果债券收益率连续 2 个月上行 + 突破关键位 → 复苏逻辑动摇，降仓位
```

## 六、中国宏观特色分析

### 6.1 信贷脉冲——A 股最重要的领先指标

```
定义：新增信贷（社融增量）的同比变化率
领先 A 股：约 6-9 个月
数据源：央行每月 10-15 号发布社融数据

历史规律（不是预测，是已发生的统计模式）：
  信贷脉冲从底部回升 > 2 个月 → A 股 6 个月后上涨概率约 70%（样本：2009-2025）
  信贷脉冲从顶部回落 > 3 个月 → A 股面临调整压力
  2015 例外：信贷脉冲回落但股市继续涨（杠杆牛市，信贷脉冲失效）

当前用法：
  不要用来择时，用来判断"当前的股市上涨有没有流动性支撑"
  基本面好转 + 信贷脉冲上行 = 最理想的组合
  基本面好转 + 信贷脉冲下行 = 后续动力不足，只能赚业绩增长的钱
```

### 6.2 M1-M2 剪刀差

```
M1（活期）增速 - M2（定期+储蓄）增速 → 反映资金活化程度

历史规律：
  剪刀差上升 → 资金从定期搬向活期 → 准备花/投资 → A 股利好（滞后 3-6 月）
  剪刀差下降 → 资金沉淀为定期 → 惜投惜消 → A 股利空
  -5% 以下 → 极度悲观，往往是底部区域
  持续 3 个月以上的反转 → 趋势信号

失效条件：
  2015 年股市大涨时剪刀差未明显扩张（配资/两融替代了传统信贷）
  2020 年疫情后剪刀差短暂跳升后迅速回落（一次性冲击）
```

### 6.3 房地产周期——中国经济的贝塔

```
关键指标优先级：
  ① 30 城商品房销售面积（周度）→ 最领先
  ② 二手房挂牌价指数 → 价格信号比成交量滞后 3-6 月
  ③ 新开工面积 → 开发商预期
  ④ 土地出让金 → 地方政府财力

对股市的传导：
  地产销售企稳 → 6 个月后家电/家具/建材需求回暖 → 9 个月后银行坏账压力缓解
  地产持续下行 → 居民财富缩水 → 消费抑制 → 通缩压力
  → 地产是中国几乎唯一的「信用发动机」，地产不企稳，宽信用难以持续
```

### 6.4 政策周期——中国特色的最大变量

```
政策信号的层级（重要度递减）：
  政治局会议（每季度一次）→ 定调子
  中央经济工作会议（每年 12 月）→ 定明年方向
  国常会 → 具体措施
  央行货币政策报告（每季度）→ 流动性基调
  证监会/各部委

有用的分析方法（不是看标题，是看"边际变化"）：
  同一件事，表述从"坚决遏制"→"防止过快上涨"→"稳定"→"支持合理需求"
  → 政策的边际变化比政策的绝对方向更重要
  → 2018 年 10 月政治局会议提出"六个稳"→ 政策底确认
  → 2018 年 12 月中央经济工作会议不提"去杠杆"→ 政策全面转向

中国特色的困境：
  政策底 ≠ 市场底（通常滞后 3-6 月）
  政策底 ≠ 经济底（滞后 6-12 月）
  → 看到政策转向就满仓 = 买在左侧，可能要扛 3-6 个月的继续下跌
```

## 七、市场状态诊断（融合原 12 号择时与情绪）

### 7.1 估值分位——决定预期收益空间

```
A 股（沪深 300）：
  数据：PE（TTM）+ PB + 股息率，各算近 5 年和近 10 年分位
  规则：
    5 年分位 < 20% + 10 年分位 < 30% → 低估区域，可以积极
    5 年分位 > 80% → 高估区域，只卖不买
    5 年分位 20-80% → 正常，看其他信号
  ⚠️ 银行股拉低整体 PE——用中位数 PE 代替加权 PE 更有参考意义

港股（恒生指数）：
  历史 PE 中枢约 11-13x。PE < 9x = 极度低估。PE > 15x = 偏贵。
  港股的低估可以持续很久（2015-2016，2021-2022，2023-2024），
  不是因为市场错了——是因为流动性结构性流失 + 中国风险溢价。
  
美股（标普 500）：
  用席勒 CAPE + 巴菲特指标（总市值/GDP）。当前大约 35x+ CAPE = 历史第三高。
  CAPE > 25 → 未来 10 年预期收益降低。
  ⚠️ CAPE 高不意味着短期会崩——只意味着赔率变差。
```

### 7.2 情绪指标——极度悲观/乐观是做反向的最好信号

| 指标 | 极度悲观 | 极度乐观 | 数据源 |
|------|------|------|------|
| A 股成交额/换手率 | 两市成交 < 5000 亿 | > 1.5 万亿 | 沪深交易所 |
| 融资余额变化 | 连续 2 周净偿还 | 连续 2 周净买入且增速>3% | 中证金融 |
| 新基金发行 | 偏股型月发行 < 100 亿 | > 800 亿（高点信号）| Wind |
| 北向资金 | 连续 5 日净流出 > 200 亿 | 连续 5 日净流入 > 300 亿 | 沪深港通 |
| 沪深 300 波动率 | VIX 类指标处于近 2 年低位 | 处于近 2 年高位 | 自行计算 |
| 新增投资者 | 月增 < 80 万 | > 200 万 | 中国结算 |

```
使用规则（关键——不是看数字，是看边际变化 + 极端位）：
  └─ 多个指标同时极端 + 估值极端 → 强信号
  └─ 单一指标极端 → 弱信号，可能只是噪音
  └─ 情绪极端 ≠ 立刻反转——可以极端再极端（2015 年 3-6 月）
  └─ 用法：情绪极端 + 技术面确认（底背离/放量突破）= 执行
```

### 7.3 市场广度——趋势的质量，不只是方向

```
关键广度指标：
  ├─ 腾落线（A/D Line）：上涨家数 - 下跌家数的累计值
  │   → 指数新高 + 腾落线不新高 = 背离，上涨广度收窄 → 警告
  ├─ % 站上 50 日均线：沪深 300 成分股中股价 > 50MA 的比例
  │   → < 30% = 超卖，> 80% = 超买
  ├─ 新高/新低比：创 52 周新高家数 / 创 52 周新低家数
  │   → 比值趋势性下滑 → 市场内部在恶化
  └─ 指数间确认：沪深 300 + 中证 500 + 创业板 同时突破 = 真突破
      → 只有上证 50 拉，中小盘不动 = 国家队护盘，不是真行情
```

## 八、综合判断框架

### 8.1 周期定位矩阵（每次宏观分析必填）

```
┌─────────────────┬──────────────────┬─────────────────┐
│  框架            │  当前判断         │  置信度         │
├─────────────────┼──────────────────┼─────────────────┤
│ Dalio 债务周期   │  {阶段}          │  高/中/低       │
│ Pring 六阶段     │  第{1-6}阶段     │  高/中/低       │
│ ML 时钟          │  {复苏/过热/滞胀/衰退} │ 高/中/低  │
│ Murphy 跨市场    │  {确认/背离/矛盾} │  高/中/低       │
│ Marks  pendulum  │  {贪婪/中性/恐惧} │  高/中/低       │
│ 中国信贷脉冲     │  {扩张/收缩/拐点} │  高/中/低       │
│ 估值分位         │  {低估/合理/高估} │  高/中/低       │
│ 市场情绪         │  {极度悲观/中性/极度乐观} │ 高/中/低 │
└─────────────────┴──────────────────┴─────────────────┘
```

### 8.2 矛盾暴露协议（这是整个文件最有价值的部分）

当不同框架给出矛盾结论时，**不强行调和**。按以下协议处理：

```
Step 1：列出所有矛盾点
  例："ML 时钟说复苏，但 Murphy 显示债券收益率在涨 + 美元走强"

Step 2：判断矛盾性质
  同层矛盾（两个中期框架打架）：
    → 降该层的置信度
    → 看短期流动性信号倾向哪边
  跨层矛盾（长期 vs 中期打架）：
    → 长期框架定仓位上限（一旦触发不轻易改）
    → 中期框架定短期倾向
    → 例：Dalio 说去杠杆（长期风险资产低配），Pring 说阶段二（中期利好）
      → 操作：参与，但仓位上限不超长期框架限制

Step 3：指定裁决指标
  为每个矛盾指定一个"裁判"——什么数据出现可以判断哪边对？
  例："债券收益率连续 2 月下行 + DXY 跌破 100 → Murphy 转向支持复苏"
  例："社融连续 3 月加速 + PMI > 51 → 复苏确认"

Step 4：当前操作建议
  矛盾未解决前：
    ├─ 按最保守的框架设仓位上限
    ├─ 不下重注
    └─ 等裁判指标明确后再加仓

  矛盾解决后：
    └─ 可以按一致性方向调整仓位
```
