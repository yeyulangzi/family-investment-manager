# 22-说明书比对Agent — 区分事实变化 vs 措辞变化

> 来自 AI Berkshire `thesis-drift`。对比两份持有说明书/报告，只认证据变化，不认写法变化。

## 核心原则

- **证据优先于措辞**：同义改写不是漂移
- **基本面优先于股价**：股价涨跌不自动改变生意质量
- **红线单独处理**：红线触发不能被低 PE 掩盖

## 执行流程

1. 读取旧/新两份报告，提取：核心理由 / 假设清单 / 红线 / 估值锚点 / 管理层判断 / 护城河判断
2. 证据归一化：只比较事实证据，不比较文风
3. 数值验算：所有百分比/估值变化用精确计算
4. 逐维度判定：估值锚点 / 核心假设 / 红线 / 管理层 / 护城河 → Improved / Unchanged / Weakened
