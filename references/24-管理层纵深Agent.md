# 24-管理层纵深Agent — 买股票就是买人

> 来自 AI Berkshire `management-deep-dive`。当 03-基本面研究Agent 步骤 8 管理层评分不确定（★★★ 或以下）、或管理层是核心变量时启用。

## 第一步：识别关键人

| 角色 | 姓名 | 任期 | 背景 | 持股 |
|------|------|------|------|------|
| CEO | | | | |
| 创始人（如不在位）| | | | |
| 实际控制人 | | | | |

区分"谁在做决策"和"谁的名字在头衔上"（如黄峥之于拼多多）。

## 第二步：诚信度评估（最重要，35% 权重）

### 承诺兑现追踪（过去 3 年）

| # | 时间 | 承诺 | 场合 | 兑现 | 评价 |
|---|------|------|------|:--:|------|
| 兑现率 = ___%，>80%=优秀，<40%=不可信赖

### 困难时期表现

| 危机事件 | 时间 | 管理层反应 | 事后评价 |
| 是主动沟通还是躲避？归因内部还是甩锅外部？

### 对利益相关方态度
| 股东/员工/客户/供应商/监管 → 尊重？利用？漠视？

## 第三步：能力评估（50% 权重）

### 战略眼光
| 时间 | CEO 判断 | 实际结果 | 准确度 |
| 有没有超前于市场的正确判断？

### 资本配置记录（巴菲特最看重）

**并购**：| 时间 | 标的 | 金额 | 事后回报 | 评分 |
**回购**：| 时间 | 金额 | 当时 PE | 事后回看 | 评分 |
**新业务投资**：成功率？止损纪律？

**资本配置综合评分**（1-5）：并购纪律 / 回购时机 / 分红合理性 / 新业务成功率 / 现金管理

## 第四步：治理结构

- AB 股/超级投票权？实控人持股比？VIE 结构？
- 高管薪酬占净利润比？与同行对比？激励是否与长期股东利益一致？
- 关联交易：是否公允？

## 第五步：侧面验证

- 员工评价（Glassdoor/知乎）：企业文化/管理层评价/工作强度
- 客户/商家反馈（App Store/消费者投诉）
- 行业口碑

## 第六步：CEO 离开后

- 如果 CEO 明天离开，公司能正常运转吗？
- 竞争优势依赖 CEO 个人还是组织系统？
- 继任者明确吗？

## 综合评分

| 维度 | 权重 | 评分(1-5) |
|------|:--:|:--:|
| 诚信度 | 35% | |
| 战略与执行 | 25% | |
| 资本配置 | 25% | |
| 治理结构 | 15% | |

**段永平三问**：正直吗？有能力吗？愿意把钱交给他管 10 年吗？
三个是=5 分，前两个是=4 分，只有第一个是=3 分，第一个不是=1 分（不投）。
