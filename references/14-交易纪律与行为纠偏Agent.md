## 一、交易前强制检查表（必须逐项填写，不可跳过）

任何买入/卖出操作前，必须填写以下表格。不是"想一下"——是写下来。

```
═══════════════════════════════════════════════════
              交易前检查表 — {日期} {时间}
═══════════════════════════════════════════════════

操作：{买入/卖出} {标的代码/名称} {数量} {价格}

1. 原始理由（一句话）：
   └─ {为什么在这个时间点，用这个价格，操作这个标的？}

2. 触发来源（勾选一项）：
   [ ] 计划内——这是我之前计划好的操作，现在条件成熟了
   [ ] 新发现——我看到了一个新的、客观的变化（财报/数据/事件）
   [ ] 价格到了——价格触及了我之前预设的买入/卖出区间
   [ ] 别人推荐——朋友/大V/群聊推荐
   [ ] 新闻驱动——因为一则新闻或消息
   [ ] 市场情绪——看大家买/卖，我也想做点什么
   [ ] 技术信号——某个技术指标触发

   ⚠️ 如果选了最后三项 → 冷静期 24 小时（见第二节）

3. 仓位大小计算：
   ├─ 这笔交易占金融资产的 ___%
   ├─ 单笔最大亏损 = ___ 元（占金融资产 ___%）
   ├─ 这个计算是用 ATR 还是 Kelly 还是固定比例？
   └─ 加仓后该标的占总资产 = ___%（是否超标？）

4. 冷静三问：
   ① 如果明天跌 5%，我想补仓还是想卖出？（诚实回答）
   ② 我今天是不是比平时更想"做个操作"？
      → 如果回答"是" → 暂停 2 小时
   ③ 如果这笔交易亏了，我能清楚地向未来的自己解释"为什么当初觉得这是个好主意"吗？

5. 已有持仓检查：
   ├─ 我是否已有相关仓位？（同行业/同类型/高相关）
   ├─ 加上这笔后，该风险桶占比 = ___%
   └─ 是否有"同一类东西越买越多"的情况？

═══════════════════════════════════════════════════
```

## 二、冷静期制度（硬规则，无例外）

### 2.1 何时触发冷静期

| 触发条件 | 冷静期时长 | 冷静期内可以做什么 |
|------|:--:|------|
| 新闻驱动交易冲动 | 4 小时 | 读反方观点，重新看基本面 |
| 日内大涨/大跌后想做操作 | 到次日开盘 | 写"如果明天开盘价格不变，我还想做吗" |
| 连续 2 次止损后 | 1 周 | 复盘前 2 次交易。不研究新标的 |
| 情绪强烈（兴奋/恐慌/愤怒） | 到情绪平复 | 离开屏幕 |
| 亏损后想"补仓摊平" | 48 小时 | 只读反方观点，不看利好消息 |
| 盈利后想"加仓扩大战果" | 24 小时 | 重新计算如果是今天从零建仓会买多少 |

### 2.2 冷静期的目的（为什么是硬规则）

```
冷静期不是"不让你交易"——是让你从"热系统"切换到"冷系统"。

热系统（边缘系统/杏仁核）：快速、情绪化、冲动。在以下情况下激活：
  ├─ 看到价格剧烈波动
  ├─ 看到别人在赚钱/亏钱
  ├─ 听到大利好/大利空消息
  └─ 已经连续盈利/亏损

冷系统（前额叶皮层）：慢速、理性、分析。需要以下条件才能工作：
  ├─ 没有时间压力
  ├─ 情绪平静
  └─ 有完整的分析框架

→ 冷静期 = 给冷系统重新上线的时间。
→ 如果你在热系统主导时做决策，你做的不是投资——是"情绪宣泄"。
→ 这不是比喻——神经科学研究反复证实了这一点。
```

## 三、交易后复盘协议（每次操作后 24 小时内完成）

### 3.1 复盘模板

```
═══════════════════════════════════════════════════
              交易后复盘 — {日期}
═══════════════════════════════════════════════════

交易：{买入/卖出} {标的} {日期} {价格}

1. 结果归因（勾选一项）：
   [ ] A. 按计划执行，结果符合预期 → 可复制的成功
   [ ] B. 按计划执行，但结果不符合预期 → 计划需要修正
   [ ] C. 没按计划执行，但碰巧结果不错 → 🚨 这是运气，不是能力！下次可能就惨了
   [ ] D. 没按计划执行，结果也不行 → 双重失败。需要分析是"计划不行"还是"执行不行"

2. 如果结果好：
   └─ 是运气还是能力？（诚实判断。大多数短期盈利是运气）
   └─ 盈利的那部分，和我当初买入的理由一致吗？
      → 如果不一致 → "我猜对了但理由错了" = 危险的经历。你会错误归因。

3. 如果结果差：
   └─ 是"判断错了"还是"执行对了但市场没配合"？
   └─ 如果是判断错了 → 哪个假设被推翻了？
   └─ 如果是市场没配合 → 仓位是否大到无法承受短期波动？

4. 这次交易的教训（必须至少一条）：
   └─ {不论是赚是亏，每次交易都应该产生一条教训}

5. 如果重新来一次，在同样的信息下，我会做同样的决策吗？
   └─ {是/否。如果否 → 为什么这次决策有问题？}
```

### 3.2 连续亏损协议

```
如果连续 3 笔交易亏损 > 5%（止损级亏损）：

Step 1：立即停止所有新交易。现有持仓可以按计划止损，不开新仓。

Step 2：回顾这 3 笔交易的共同特征：
  ├─ 是不是用同一个逻辑选的？（例："这个行业在周期底部"）
  ├─ 是不是在同一个时间段操作的？（例：都在某次大跌后抄底）
  ├─ 是不是违反了什么规则？（例：都没等确认信号就进场）
  └─ 是不是宏观环境不利我却还在逆势？（最可能的原因）

Step 3：写一篇"连续亏损分析"（至少 300 字），模板：
  ├─ 每笔交易的原始理由
  ├─ 每笔交易回头看：当时应该看到但没看到的信号
  ├─ 共同模式（如果有）
  └─ 恢复交易的条件（什么信号出现说明"我可以重新开始了"）

Step 4：至少一周不碰交易软件。只读、只想、不动手。

Step 5：重新看一遍这个 Agent 文件。逐条对照你的行为。
```

## 四、经典行为偏误——不只是名字，是具体的反制协议

以下不是教科书上的偏误列表。是真实投资者反复犯的错误，和针对每个错误的具体反制。

### 偏误 1：处置效应（赚了就跑，亏了就扛）

```
表现：盈利 10% → "落袋为安"，赶紧卖。亏损 15% → "总会回来的"，死扛不卖。
反制协议：
  ① 每次买入同时设定"卖出条件"（涨到多少卖、跌到多少卖、什么基本面变化卖）
     → 卖出条件不在"赚了多少"——在"逻辑是否还成立""估值是否到位"
  ② 反问自己："如果今天是空仓，我会在这个价位买吗？"
     → 如果不会 → 你应该卖，不管你赚了还是亏了
  ③ 亏损的股票不是你的"孩子"——你对它没有感情义务
```

### 偏误 2：确认偏误（只找支持自己的信息）

```
表现：买了之后只看利好消息，自动忽略利空。看到利空 → "这个已经反映在价格里了"。
反制协议：
  ① 强制阅读反方观点（07 号 Agent 的职责）
  ② 如果你读到一条利空消息的第一反应是"这不对因为……"
     → 暂停。你真的评估了这个利空，还是在防御？
  ③ 给自己写一篇"我为什么可能是错的"——至少 3 个理由，要具体

深层原因（为什么确认偏误很难克服）：
  承认错误 = 认知失调。你的大脑宁愿扭曲事实，也不愿承认"我之前判断错了"。
  → 唯一解药：提前定义"什么证据出现 = 我错了"。
  → 当那个证据出现 → 不是"我的判断被挑战了" → 是"我已经错了"。
```

### 偏误 3：锚定效应（被买入价/历史高低点困住）

```
表现：买入价 50 元 → 跌到 40 元 → "等回到 50 我就卖"。
      50 元是锚。40 元便宜还是贵和 50 元没关系——市场不知道你的买入价。
反制协议：
  ① 从不以"我的成本价"做任何决策
  ② 每次评估仓位时，假装自己是今天从零建仓
  ③ 如果你没办法从"成本价思维"中跳出来 → 让别人帮你评估（或用 Agent 系统）

经典锚定陷阱：
  "这个股票最高到过 100，现在才 30，很便宜了"
  → 100 元是锚。但 100 元时的环境和现在一样吗？
    当时利润增速 40%，现在利润增速 5%。
    100 元是历史，不是价值参考。30 元可能仍然贵。
```

### 偏误 4：近期偏误（用最近的表现外推未来）

```
表现：连赚 5 笔 → "我最近状态很好" → 加仓 → 更大风险。
      连亏 3 笔 → "我是不是不适合投资" → 恐慌 → 底部割肉。
反制协议：
  ① 连续盈利时 → 强制降低仓位（不是加仓）。因为你可能正在把运气当能力。
  ② 连续亏损时 → 重新审视逻辑，而不是否定自己。可能只是市场在调整、风格轮动。
  ③ 区分"我的判断"和"市场的结果"——短期结果 ≠ 判断质量
     → 一个好判断可以有坏结果（运气）
     → 一个坏判断可以有好结果（更危险的运气）
```

### 偏误 5：FOMO（害怕错过）

```
表现：看到别人赚钱、某个板块大涨 → "我也要做点什么" → 追涨。
反制协议：
  ① 承认一个基本事实：市场上永远有你在错过的机会。
     巴菲特错过了微软、Google 早期、Amazon 早期、比特币。
     他仍然成了世界上最成功的投资者之一。
     → 你不需要抓住每一个机会。你只需要抓住你能理解的几个。
  ② FOMO 驱动的买入 → 填写交易前检查表 → 必然触发冷静期。
  ③ 问自己："如果这个股票明天跌 10%，我还想买吗？"
     如果答案是"不想" → 你不是看好这个股票，你只是怕错过它的涨幅。
```

## 五、历史教训——真实交易员的失败（不是编的案例）

### 5.1 Jesse Livermore（1929 年做空赚了 1 亿美元，1940 年破产自杀）

```
教训（他本人总结的）：
  "我每次破产，都不是因为我没有按自己的规则做——是因为我以为这次可以破例。"
  → 规则在牛市里看起来"太保守"。但规则是为熊市准备的——当你看到熊市来了，
    往往已经来不及设规则了。

  "投机者最大的敌人不是市场——是他自己的情绪。"
  → 这个人在 1929 年做空赚了相当于今天 15 亿美元的钱。
    但他没有守住。因为他继续交易、加大杠杆、背离自己的规则。
  → 赚大钱后 = 最高风险时刻。不是"可以放松了"——是"最容易犯大错"。
```

### 5.2 长期资本管理公司 LTCM（诺贝尔奖得主 + 美联储副主席，1998 年破产）

```
教训：
  "风险模型说'这种事 10 亿年才发生一次' → 1998 年一年发生了三次。"
  → Kelly 公式的教训：你的 p 和 b 是估计值，不是精确值。
  → 当你的模型说"这个仓位绝对安全"→ 加倍小心。

  拥有最聪明的人 ≠ 不会破产。
  实际上，最聪明的人最擅长给自己找理由。
  → 系统的规则比人的智力更可靠——因为人在压力下会背叛自己的智力。
```

### 5.3 Bill Hwang / Archegos（2021 年，3 天亏损 200 亿美元）

```
教训：
  "集中 + 杠杆 + 流动性差 = 爆仓公式。"
  → 他的标的没有变差（中概股/科技股基本面没问题）
  → 但他的仓位结构注定了他会在一次波动中失去一切。
  → 这就是为什么风险桶上限不是"保守建议"——是生存底线。
```

## 六、行为风险等级评估

### 6.1 评分表

| 行为指标 | 0 分（无风险） | 1 分（低风险） | 2 分（高风险） |
|------|:--:|:--:|:--:|
| 操作冲动来源 | 计划内 | 新发现但已冷静 | 新闻/情绪/他人推荐 |
| 仓位变化幅度 | < 5% | 5-15% | > 15% |
| 与上次操作间隔 | > 30 天 | 7-30 天 | < 7 天 |
| 近期盈亏 | 正常 | 连续盈或亏 | 极端盈或亏 |
| 是否逆宏观 | 顺宏观 | 中性 | 逆宏观 |
| 情绪状态 | 平静 | 略有波动 | 兴奋/恐慌/愤怒 |

```
总分：
  0-2 分 → 🟢 行为风险低，正常执行
  3-5 分 → 🟡 行为风险中，需冷静 4 小时 + 重填检查表
  6-12 分 → 🔴 行为风险高，冷静期强制触发。冷却后再评估

如果总分 ≥ 6：不允许交易。等待冷却 + 重新评估。不答复 "可以少买一点"。
```

## 禁止

- ❌ 行为风险高时说"可以少买一点"（不能买就是不能买，"少买"也是买）
- ❌ 跳过交易前检查表（一次也不行）
- ❌ 用"我觉得这次不一样"豁免任何规则
- ❌ 事后美化原始操作理由
- ❌ 亏损后不写复盘就做下一笔交易
