# 行业研究与主题投资方法论

> 创建：2026-07-07 | 融合 AI Berkshire /industry-research + 行业 ETF 对比选择

## 1. 这套方法回答什么问题

行业研究不回答"这只股票能不能买"，它回答：

1. **这个行业处于什么生命周期阶段？**（导入/成长/成熟/衰退）
2. **钱在这个行业里是怎么分配的？**（谁是最大赢家、谁是苦力）
3. **当前估值在历史上处于什么位置？**（便宜还是贵）
4. **买哪只 ETF 最好？**（跟踪误差、费率、规模、持仓重叠）
5. **什么信号应该进入、什么信号应该退出？**

---

## 2. 行业生命周期定位

每个行业必须先定位阶段，不同阶段的投资逻辑完全不同：

| 阶段 | 特征 | 投资逻辑 | 估值方法 | 风险 |
|------|------|---------|---------|------|
| **导入期** | 技术不成熟、商业模式未验证、渗透率 <5% | 选龙头、小仓位、等拐点 | PS 或市场规模倒推 | 极高——技术路线可能被淘汰 |
| **成长期** | 渗透率 5%-30%、增速 >20%、竞争涌入 | 选龙头 + 产业链关键环节 | PEG 或远期 PE | 中高——估值泡沫 |
| **成熟期** | 渗透率 30%-60%、增速 5-15%、格局稳定 | 选龙头、看重 ROE 和分红 | PE 分位 + DDM | 中——增速放缓杀估值 |
| **衰退期** | 需求萎缩、产能过剩、并购整合 | 回避或做空 | PB 或清算价值 | 中——价值陷阱 |

**定位方法**：
- 渗透率：当前市场渗透率 vs 理论天花板
- 增速趋势：行业收入/利润增速是加速还是减速
- 资本开支方向：行业 CAPEX 是在扩张（成长期）还是维持（成熟期）
- 新进入者：还有新玩家涌入吗？

## 3. 产业链全景扫描（核心）

不画产业链，就不算做了行业研究。

```
上游（原材料/设备）  →  中游（制造/加工）  →  下游（应用/终端）
       │                      │                      │
   谁有定价权？          谁有规模壁垒？         谁离客户最近？
```

### 3.1 产业链四步法

**第一步：画出产业链。** 从原材料到终端消费者，每个环节列出 2-3 家头部公司。

**第二步：定位利润池。** 整个产业链的总利润，在每个环节是怎么分配的？
- 上游有资源定价权吗？（如 ASML 光刻机）
- 中游有规模壁垒吗？（如台积电代工）
- 下游有品牌溢价吗？（如苹果）

**第三步：找出瓶颈环节。** 哪个环节是整个产业的约束？
- 瓶颈 = 定价权最强 ≠ 规模最大
- AI 产业链的瓶颈在 HBM 内存和先进封装

**瓶颈猎手三问（2026-07-07 融合 AI Berkshire bottleneck-hunter）：**

定位瓶颈不只是找"最赚钱的环节"——瓶颈的三重验证：

1. **物理约束**：哪个环节的产能扩张最慢？（建厂周期 >3 年、良率爬坡 >1 年、设备供应有限）
2. **竞争约束**：哪个环节的供应商最少？（全球 ≤3 家、新进入者需要 10 年+技术积累）
3. **技术约束**：哪个环节的产品不可替代性最强？（下游客户切换成本极高、性能差距无法用价格弥补）

→ 瓶颈 = 三问都得分最高的环节
→ 瓶颈环节的公司在超级周期中最受益，且下跌时抗跌性最强

**第四步：判断竞争强度。**
- 每个环节的进入壁垒
- 替代威胁（技术替代 + 中国国产替代）
- 买方/卖方议价力

## 4. 行业估值框架

个股看 PE，行业看 PE 分位 + ROE 趋势。

### 4.1 估值分位

| 数据 | 来源 | 怎么用 |
|------|------|--------|
| 行业 PE 当前值 | AKShare / 腾讯 qt | 绝对值 |
| PE 历史分位（3年/5年/10年） | AKShare / 东方财富 | 当前在历史上的位置 |
| PB 分位 | 同上 | 重资产行业更看 PB |
| 盈利增速趋势 | AKShare 财务数据 | 高增长可以给高 PE，但要验证 |

**判断规则**：
- PE 分位 <30% + 盈利增速向上 → 可能低估
- PE 分位 >80% + 盈利增速放缓 → 大概率高估
- PE 分位在中间 + 增速不确定 → 信息不足，不急着判断

### 4.2 ROE 趋势

行业 ROE 的长期趋势比短期 PE 更重要：
- ROE 趋势向上 → 行业在变好
- ROE 趋势向下 → 即使 PE 低也可能是价值陷阱

## 5. 行业 ETF 对比选择

同一个行业通常有多只 ETF 可选。选错 ETF 可能比选错行业更亏。

### 5.1 对比维度

| 维度 | 权重 | 怎么查 | 好 | 差 |
|------|:--:|------|------|------|
| **跟踪指数** | ★★★★★ | 基金公告/天天基金 | 编制规则合理、代表性强 | 小众指数、成分股太少 |
| **费率** | ★★★★ | 天天基金/ttskill | 管理费 <0.5% | 管理费 >1% |
| **规模** | ★★★ | 同上 | >10 亿（流动性好） | <2 亿（清盘风险） |
| **跟踪误差** | ★★★★ | 同上 | <2% | >5% |
| **持仓集中度** | ★★★ | 季报/基金穿透 | 前 10 大 <50% | 前 3 大 >40% |
| **日均成交额** | ★★★ | 行情软件 | >5000 万 | <1000 万（难买卖） |
| **与已有持仓重叠** | ★★★★★ | 持仓对比分析 | 不重叠 | 和现有基金买的一样 |

### 5.2 数据获取优先级

```
ETF 数据获取优先顺序：
1. AKShare（fund_etf_spot_em / fund_etf_fund_info_em）→ A 股 ETF
2. ttskill（天天基金）→ A 股基金详情/持仓/费率
3. futuapi（需 OpenD）→ 港美股 ETF
4. 腾讯 qt 行情 → 实时价格
5. 网页搜索（天天基金网页/东方财富）→ AKShare 不可用时的降级
   ⚠️ 网页搜索数据必须至少两个独立信源交叉验证
```

## 6. 行业买入/卖出信号

### 买入信号（至少满足 2 个）

- [ ] 行业 PE 分位 < 40%（相对便宜）
- [ ] 行业盈利增速触底回升或持续 >10%
- [ ] 产业链瓶颈环节供给紧张（有利于涨价）
- [ ] 政策催化（补贴、退税、国产替代）
- [ ] 市场情绪悲观但基本面未恶化（逆向）

### 卖出信号（任一满足即考虑）

- [ ] PE 分位 > 90%
- [ ] 盈利增速连续 2 季下滑
- [ ] 产业链瓶颈缓解（供给过剩）
- [ ] 技术替代风险兑现
- [ ] 持仓 ETF 规模跌破 2 亿（清盘风险）

## 7. 常见误判

- 把"行业空间大"等同于"现在能赚钱"——导入期行业空间最大，但死掉的也最多
- 用个股框架分析行业 ETF——行业 ETF 不产生超额收益，关键是配置时机和费率
- 只看 PE 不看 ROE 趋势——低 PE 可能是价值陷阱
- 选最便宜的 ETF——费率差 0.3% 但跟踪误差差 3%，得不偿失
- 和已有持仓买成一样的——科创 50 + 芯片 ETF + 纳指可能有 60% 持仓重叠

## 8. 行业漏斗筛选（2026-07-07 融合 AI Berkshire industry-funnel）

不直接跳到行业深度分析。先过三层漏斗，淘汰不值得花时间的行业。

### 第一层：估值否决（快速扫）

- [ ] 行业 PE 分位 > 80%（贵得不值得看）
- [ ] ROE 连续 2 年下滑（行业在变差）
- [ ] 任一触发 → 直接剔除，不进入下一层

### 第二层：趋势否决

- [ ] 盈利增速 < 0 且未见拐点（还在恶化）
- [ ] 行业 CAPEX 连续 2 年缩减（企业自己都不投了）
- [ ] 政策明确打压（如教培双减级别）
- [ ] 任一触发 → 剔除

### 第三层：深度分析

- [ ] 通过前两层的行业，进入 8 步完整工作流
- [ ] 精选 2-3 个行业，按"组合互补性"选（高确定性 + 中弹性），不按打分前 3 排序
- [ ] 每个被淘汰的行业注明淘汰理由

### 输出格式

```
漏斗筛选结果：
├─ 初筛：X 个行业 → 第一层剔除 Y 个 → 第二层剔除 Z 个 → 终选 N 个
├─ 推荐组合：
│   ├─ 核心配置：行业A（理由：估值低+ROE向上）
│   └─ 卫星配置：行业B（理由：高弹性+周期拐点）
├─ 淘汰记录：
│   ├─ 行业C：PE分位85%，剔除
│   └─ 行业D：盈利增速连续3季为负，剔除
└─ 待观察：行业E（PE分位合理但ROE趋势不明，1个月后重评）
```
