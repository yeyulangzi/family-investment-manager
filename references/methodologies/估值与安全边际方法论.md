# 估值与安全边际方法论

## 1. 这套方法回答什么问题

估值不是为了算出一个精确价格，而是为了回答：

1. 当前价格隐含了什么未来？
2. 这个未来需要多乐观才成立？
3. 如果未来比预期差一点，是否仍然不亏大钱？
4. 当前资产相对其他可选资产是否划算？

估值的目标不是“证明可以买”，而是防止为好故事付过高价格。

## 2. 核心思想

### 安全边际

安全边际来自四个地方：

1. **价格折扣**：价格显著低于保守内在价值。
2. **资产保护**：现金、净资产、可出售资产或稳定现金流提供底部。
3. **生意质量**：高资本回报、强护城河和可持续现金流降低长期不确定性。
4. **组合约束**：即使判断错了，仓位也不会造成不可承受损失。

不是真正安全边际的东西：

- “大家都看好”
- “行业空间很大”
- “跌了很多”
- “长期肯定会回来”
- “技术面到底了”
- “我不卖就不亏”

### 价格隐含预期

估值不是先问“值多少钱”，而是先问：

> 现在这个价格要求公司未来做到什么？

落地方式：

- 当前市值对应多少收入、利润、自由现金流？
- 如果用当前价格买入，未来 3-5 年需要多少增长和利润率才能获得合理回报？
- 市场当前是在定价复苏、成长、垄断、周期反转，还是资产重估？
- 哪个假设一旦不成立，估值就塌？

### 相对机会成本

任何投资都不是孤立的。

必须和这些选择比较：

- 现金和货币基金
- 国债或债券基金
- 宽基指数
- 同行业更优公司
- 黄金或其他防守资产
- 继续等待

如果一个标的看起来“可以”，但相对其他资产没有明显优势，不应给强结论。

## 3. 估值方法库

### DCF：现金流折现

适用：

- 现金流较稳定
- 商业模式可理解
- 能对未来增长、利润率和资本开支做合理假设

核心变量：

- 收入增长
- 利润率
- 税率
- 资本开支
- 营运资本
- 折现率
- 永续增长率

落地要求：

- 至少做乐观、中性、悲观三种情景。
- 折现率和永续增长率不能随意调到想要的结果。
- 对强周期、强监管、强技术变化公司，DCF 可靠性下降。
- DCF 输出应是区间，不是单点价格。

### 倍数估值

适用：

- 同行业有可比公司
- 盈利或收入指标相对稳定
- 市场对同类资产有相对成熟定价

常用指标：

- PE：适合盈利稳定公司。
- PB：适合银行、保险、周期底部资产、资产重公司。
- PS：适合暂时利润低但收入质量可分析的成长公司。
- EV/EBITDA：适合资本结构差异较大的公司。
- FCF Yield：适合现金流质量高的成熟公司。

落地要求：

- 倍数必须和增长、ROIC、利润率、风险一起看。
- 低 PE 可能是价值陷阱，高 PE 可能是高质量，但都不能直接下结论。
- 同行比较必须解释为什么应该高于、等于或低于同行。

### 资产价值法

适用：

- 资产重公司
- 金融公司
- 周期底部公司
- 清算价值、净现金、隐蔽资产明显的公司

落地要求：

- 区分账面价值和可变现价值。
- 对存货、应收、商誉、长期股权投资做折价。
- 对高负债公司提高折价率。
- 资产价值只能提供底部参考，不能自动代表上涨空间。

### 分部估值

适用：

- 多业务公司
- 平台型公司
- 一部分成熟、一部分成长的公司
- 控股型公司

落地要求：

- 每个业务单独判断增长、利润率、资本需求和风险。
- 不同业务用不同估值方法。
- 控股折价、管理成本和资本配置风险必须反映。

### 周期估值

适用：

- 上游资源
- 航运、化工、钢铁、地产链
- 强周期金融资产

核心方法：

- 用周期平均利润，而不是景气高点利润。
- 看供给扩张、库存、价格、资本开支周期。
- 在高景气低 PE 时警惕价值陷阱。
- 在低景气高 PE 或亏损时反而可能接近底部。

## 4. 不同资产的估值方式

### 个股

必须同时看：

- 绝对估值：保守内在价值区间。
- 相对估值：与同行、历史、宽基指数比较。
- 隐含预期：当前价格要求未来做到什么。
- 下行情景：如果核心假设错了会亏多少。

### 指数基金和 ETF

估值重点：

- 指数整体 PE、PB、股息率、ROE。
- 历史分位。
- 成分行业和国家结构。
- 盈利周期位置。
- 汇率和利率环境。

输出不写“目标价”，而写：

- 当前位置：低估 / 合理 / 高估。
- 适合策略：定投 / 分批 / 等待 / 再平衡。
- 组合角色：进攻 / 防守 / 分散 / 现金替代。

### 主动基金

估值重点：

- 底层持仓估值。
- 基金经理风格当前是否处在顺风或逆风。
- 规模、换手、集中度、费用。
- 最大回撤和风险暴露。

主动基金不能只按历史收益买，要拆收益来源。

### 黄金

黄金没有现金流，不能用 DCF。

判断重点：

- 实际利率方向。
- 美元信用和汇率趋势。
- 通胀预期。
- 央行需求和地缘风险。
- 组合中是否需要对冲。

黄金的估值更多是相对位置和组合功能判断，不是内在现金流估值。

## 5. 安全边际落地规则

### 买入区间

必须区分：

- 观察价：值得开始跟踪。
- 初买价：可以小仓位试探。
- 重买价：安全边际足够，可明显增配。
- 停止买入价：安全边际消失。

### 仓位和安全边际联动

- 安全边际越弱，仓位越低。
- 业务越难预测，仓位越低。
- 估值越依赖远期增长，仓位越低。
- 反方证据越强，仓位越低。
- 只有质量、估值、风险三者同时过关，才能提高仓位。

### 卖出规则

卖出不只因为上涨，也不只因为下跌。

卖出条件包括：

- 价格超过合理价值，未来收益率不足。
- 基本面逻辑失效。
- 更好的替代资产出现。
- 组合风险过度集中。
- 原买入假设被证伪。

## 6. 输出标准

任何估值输出都必须包含：

1. 使用了哪些估值方法。
2. 每个方法的核心假设。
3. 乐观、中性、悲观三种情景。
4. 当前价格隐含预期。
5. 安全边际是否足够。
6. 买入、加仓、停止买入、减仓条件。
7. 哪些数据会推翻估值结论。
