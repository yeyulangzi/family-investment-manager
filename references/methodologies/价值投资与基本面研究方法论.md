# 价值投资与基本面研究方法论

## 1. 这套方法回答什么问题

价值投资不是“买便宜股票”，也不是“长期持有就行”。

它主要回答四个问题：

1. **这个资产是不是值得拥有？**
2. **它为什么能长期创造价值？**
3. **当前价格是否给了足够安全边际？**
4. **如果判断错了，最可能错在哪里？**

在这套投资系统里，价值投资是主框架。技术分析、宏观、大类资产配置、市场情绪只能作为补充，不能替代对资产本身和价格的判断。

## 2. 核心思想来源

### 格雷厄姆：安全边际和市场先生

核心观点：

- 股票不是价格曲线，而是企业所有权的一部分。
- 市场短期会情绪化报价，投资者不必被市场情绪牵着走。
- 投资本质是用显著低于内在价值的价格买入资产。
- 安全边际是防止估值错误、经营恶化和认知偏差的缓冲垫。

核心方法：

- 区分价格和价值。
- 估算资产的保守价值，而不是乐观价值。
- 对财务质量差、负债高、盈利波动大的标的要求更高折扣。
- 在极端便宜时关注资产价值、清算价值、净现金和账面价值。

落地手段：

- 先问：如果市场一年不开盘，我是否愿意拥有这项资产？
- 写出保守情景下的价值区间，而不是只写目标价。
- 买入前必须写清安全边际来自哪里：低估值、资产折价、现金流稳定、周期底部，还是市场误解。
- 如果安全边际只来自“未来会高增长”，默认不算真正安全边际。

### 巴菲特：好生意、护城河和长期复利

核心观点：

- 长期收益主要来自企业长期创造现金流的能力。
- 好公司比便宜公司更重要，但好公司也不能用任何价格买。
- 能力圈比聪明更重要，不懂的生意不碰。
- 管理层是否理性、诚实、重视股东回报，会显著影响长期回报。

核心方法：

- 判断企业是否有可持续竞争优势。
- 判断企业是否能以较高资本回报率长期再投资。
- 关注自由现金流和所有者收益，而不是只看会计利润。
- 关注行业结构、价格权、品牌、网络效应、成本优势、转换成本。

落地手段：

- 写出公司赚钱的因果链：客户为什么买、公司为什么能赚钱、竞争者为什么抢不走。
- 检查 ROIC/ROE 的质量：是经营能力、杠杆、周期红利，还是会计处理造成的。
- 用 5-10 年视角问：这家公司会更强、更弱，还是差不多？
- 对管理层做资本配置检查：分红、回购、并购、扩张是否理性。

### 芒格：多元思维模型、反过来想和避免愚蠢

核心观点：

- 投资不是单一财务模型问题，而是商业、心理、激励、竞争、制度共同作用的结果。
- 大错误往往来自认知偏差和激励扭曲，而不是缺少复杂模型。
- 先避免愚蠢，再追求聪明。
- 好机会不多，耐心和纪律本身就是优势。

核心方法：

- 反过来想：这笔投资怎样会失败？
- 检查激励：管理层、渠道、客户、监管者、竞争者分别被什么驱动？
- 用多学科模型交叉验证：规模经济、网络效应、均值回归、激励、心理偏差、竞争优势、路径依赖。
- 识别能力圈边界：看不懂、不稳定、无法跟踪的标的不强行研究。

落地手段：

- 每次投资 memo 必须写“最可能错在哪里”。
- 每个核心假设至少找一个反证指标。
- 对高杠杆、强周期、强监管、强技术替代的标的提高安全边际要求。
- 如果分析依赖过多变量同时成立，降低判断等级。

### 费雪：定性研究和长期成长

核心观点：

- 优秀成长企业的长期价值不只来自当前资产，而来自未来多年扩大市场、改善产品和提升组织能力。
- 财务报表是结果，真正的原因在客户、产品、销售、研发、组织和行业结构里。

核心方法：

- 深入研究公司产品、客户满意度、研发能力、销售能力和管理文化。
- 关注长期增长质量，而不是短期利润波动。
- 用上下游、竞争者、客户反馈交叉验证公司叙事。

落地手段：

- 对成长股必须写清增长来源：市场扩张、份额提升、提价、产品结构、海外扩张，还是并购。
- 增长必须拆成量、价、利润率、资本投入四个部分。
- 若增长来自一次性红利或行业 beta，不能按高质量成长估值。

## 3. 基本面研究的六层结构

### 第一层：生意本质

回答：

- 公司到底卖什么？
- 客户为什么必须买？
- 购买频次、客单价、替代方案是什么？
- 需求是刚性、周期性、可选消费，还是政策/补贴驱动？

落地：

- 用一句话写清“客户问题 -> 公司产品 -> 收费方式 -> 利润来源”。
- 如果说不清公司怎么赚钱，不进入估值环节。
**赛道定义（穿透行业标签）：**

不要用市场标签定义公司。"搜索引擎公司"是隔的，不告诉你任何东西。"人类认知基础设施的垄断运营商"是穿透的——解释了它真正在做什么、钱从哪里来、为什么别人抢不走。

定义赛道时自问：
- 剥离所有品牌话术和行业术语，这家公司真正垄断/控制了什么？
- 这个东西别人能不能复制？如果不能，为什么？
- 它在创造新秩序，还是在搬运旧秩序？

赛道定义必须和估值逻辑一致——如果你说它"垄断了X"，那它的定价权、利润率、增长就应该反映这个垄断。如果不一致，说明赛道定义是错的。
### 第二层：行业结构

回答：

- 行业是增长、成熟、衰退，还是周期反转？
- 供给是否容易扩张？
- 买方和卖方谁更有议价权？
- 行业利润会被谁拿走：品牌、渠道、平台、上游、下游，还是监管？

落地：

- 使用波特五力做约束检查：竞争强度、进入壁垒、替代品、供应商议价、客户议价。
- 区分“行业空间大”和“公司能赚钱”。大市场不等于好生意。

### 第三层：竞争优势

回答：

- 公司凭什么长期比同行赚钱？
- 优势来自品牌、成本、规模、网络效应、转换成本、牌照、数据、渠道，还是组织能力？
- 这个优势是在增强还是减弱？

落地：

- 每个护城河必须对应一个可观察指标。
- 品牌看定价权和复购，不只看知名度。
- 成本优势看单位成本曲线，不只看规模大。
- 网络效应看新增用户是否提升老用户价值，不只看用户多。
- 转换成本看客户离开是否有真实损失，不只看合同绑定。

**冲击韧性：护城河的真实性在冲击中验证：**

护城河不在风平浪静时判断，在被冲击时验证。

- 回顾公司历史上经历过的重大冲击（技术变革、监管打击、竞争入侵、市场崩溃）。
- 每次冲击后，它是碎掉、扛住，还是把冲击吃进去变成自己的燃料？
- 如果有至少两次"冲击后变强"的历史记录，护城河真实性的置信度大幅提高。
- 如果历史上的冲击都靠裁员、卖资产、缩减业务来应对，护城河可能只是规模带来的缓冲，不是结构性的。

**核心算法（创生公式）：**

每台好的生意背后都有一条可压缩、可验证的核心算法。试着把它写出来：

> X → Y → Z → 回到 X 并增强它

例如：亚马逊 = 利润→再投资→降成本→降价→更多用户→更多利润。腾讯 = 社交图谱垄断→捕获每一层可货币化的交互→用现金流反哺下一代入口→加深图谱的不可替代性→提高变现效率。

写出来后回答：
- 这个公式被验证过几次？
- 别人在跑相似的公式吗？差异在哪？
- 当前新业务在这个公式的哪一环？
- 飞轮在加速还是减速？

### 第四层：财务质量

回答：

- 利润是否能转成现金？
- 增长是否需要大量资本投入？
- 毛利率、净利率、ROE、ROIC 是否稳定？
- 负债结构是否安全？
- 应收、存货、资本开支是否异常？

落地：

- 利润表看增长和利润率。
- 资产负债表看杠杆、现金、应收、存货和商誉。
- 现金流量表看经营现金流、资本开支和自由现金流。
- 高利润但低现金流的公司，必须解释差异。
- 高 ROE 公司必须拆解杠杆、利润率、周转率和真实资本回报。

### 第五层：管理层与资本配置

回答：

- 管理层是否诚实？
- 是否长期主义？
- 是否擅长资本配置？
- 是否尊重小股东？
- 股权激励是否和长期价值一致？

落地：

- 看过去承诺是否兑现。
- 看并购是否创造价值。
- 看回购是否在低估时进行，而不是高位维护股价。
- 看分红是否和现金流、再投资机会匹配。
- 看管理层是否用复杂叙事掩盖基本问题。

### 第六层：关键假设和失效条件

回答：

- 这个投资判断最依赖哪 1-3 个假设？
- 哪些数据可以证明这些假设正在成立？
- 哪些数据出现后应承认判断错误？

落地：

- 每个核心假设必须有跟踪指标。
- 每个投资 memo 必须写失效条件。
- 如果没有失效条件，说明不是投资判断，而是信念表达。

## 4. 不同资产的基本面侧重点

### 个股

重点看：

- 商业模式
- 行业结构
- 护城河
- 财务质量
- 管理层
- 估值和安全边际

### 指数基金和 ETF

重点看：

- 指数编制规则
- 底层资产行业和国家暴露
- 估值分位
- 成分股集中度
- 费用率
- 流动性和跟踪误差

### 主动基金

重点看：

- 基金经理投资框架是否稳定
- 历史收益来自能力、风格、行业 beta，还是运气
- 回撤控制和换手率
- 持仓集中度
- 规模是否影响策略有效性
- 费用是否合理

### 黄金

黄金不是能产生现金流的资产，不能按企业价值框架估值。

重点看：

- 实际利率
- 美元信用和汇率
- 通胀预期
- 地缘风险
- 央行购金
- 组合对冲功能

黄金的主要作用通常是组合保险和货币信用对冲，不应被包装成“长期复利资产”。

## 5. 常见误判

- 把好公司等同于好股票。
- 把高增长等同于高价值。
- 把低 PE 等同于便宜。
- 把高 ROE 等同于好生意。
- 把行业空间大等同于公司能赚钱。
- 把短期股价上涨等同于基本面验证。
- 把管理层叙事等同于事实。
- 把一次性周期红利当成长期竞争优势。
