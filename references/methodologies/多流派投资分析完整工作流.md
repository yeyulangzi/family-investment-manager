# 多流派投资分析完整工作流

## 1. 这套工作流回答什么问题

这套工作流不是为了写一篇“公司介绍”，而是为了把一个投资标的从信息、事实、逻辑、估值、价格行为、仓位和风险几个层面拆透，最后回答：

1. 这是不是一个值得研究的资产？
2. 它长期创造价值的机制是什么？
3. 当前价格隐含了什么预期？
4. 现在是否适合动手？
5. 应该买多少、何时复盘、什么情况承认错误？

所有公司报告都必须按这个顺序推进。不能先有结论，再找材料填充。

## 2. 总原则

- **价值投资是主干**：决定是否值得长期拥有。
- **估值是闸门**：好公司也不能无价格纪律地买。
- **技术分析是执行工具**：只决定节奏、分批、等待确认，不决定投资理由。
- **宏观和周期是环境校正**：解释折现率、风险偏好、流动性和行业景气，不单独构成买卖理由。
- **行为金融是自我防错**：识别追涨、亏损厌恶、确认偏误、锚定和叙事依赖。
- **组合管理是最终约束**：单个标的再好，也不能破坏家庭资产和金融资产的整体结构。
- **反方审查有否决权**：如果核心假设脆弱，宁可观察，不要硬给买入结论。

## 3. 报告前置动作

### 3.1 先还原上下文

分析任何公司前，必须先查：

- `{你的投资库}/公司分析/公司名/公司记忆.md`
- 同公司历史报告
- `config/资产配置记忆.md`
- `config/家庭资产.md`
- 用户当前是否已经持有、持仓成本、仓位、浮盈亏

如果用户已经持有，报告必须先回答：

- 当前持仓占金融资产多少？
- 它属于哪个风险桶？
- 是否与已有基金、个股、行业主题重叠？
- 本次分析是首次买入判断、继续持有判断、加仓判断，还是减仓判断？

### 3.2 先列信息来源

每份公司报告至少需要四类资料：

1. **公司官方资料**：年报、季报、业绩公告、投资者演示、电话会纪要。
2. **市场数据**：当前价格、市值、估值倍数、52 周区间、成交量、均线、相对指数表现。
3. **行业资料**：行业规模、竞争格局、监管变化、供需结构、竞品表现。
4. **组合资料**：用户持仓、同类资产暴露、现金比例、风险承受约束。

如果缺资料，必须写在“信息缺口”，不能用推测填平。

## 4. 价值投资主线

这一层吸收格雷厄姆、巴菲特、芒格、费雪的核心思想。

### 4.1 生意本质

必须写清：

- 公司卖什么？
- 客户是谁？
- 客户为什么买？
- 公司怎么收费？
- 利润最终来自哪里？
- 需求是高频、低频、刚性、可选、周期性，还是政策驱动？

输出格式：

```text
生意本质一句话：客户因为 X，在 Y 场景下使用 Z，公司通过 A/B/C 收费并形成利润。
```

如果这句话写不清，不进入估值。

### 4.2 商业模式拆解

必须拆：

- 收入来源：每个业务贡献多少收入。
- 成本结构：固定成本、变动成本、获客成本、履约成本、研发成本。
- 利润来源：哪一块业务真正赚钱，哪一块只是规模或战略投入。
- 现金流机制：利润能否转化成经营现金流和自由现金流。
- 增长来源：用户增长、频次提升、客单价提升、广告加载率、提价、国际化、并购，还是会计口径。

不能只写“收入增长”。要拆成：

```text
收入 = 用户数 × 使用频次 × 付费率 / 货币化率 × 客单价 / ARPU
利润 = 收入 × 毛利率 - 获客/履约/研发/管理/资本开支
```

### 4.3 行业结构

使用波特五力和平台经济视角：

- 竞争强度：是寡头、双寡头、分散竞争，还是价格战？
- 进入壁垒：品牌、网络效应、规模、牌照、数据、供应链、资金、渠道。
- 替代品：客户能否轻易换到别的平台或产品？
- 买方议价权：客户是否敏感于价格、体验、迁移成本。
- 供应商议价权：商家、内容方、开发者、上游资源方是否会拿走利润。
- 监管约束：反垄断、数据、金融、内容、游戏、跨境、税务、关税。

行业大不等于公司好。报告必须写：

- 行业利润最终被谁拿走？
- 这个公司处在利润链条的哪个位置？
- 现在行业是在扩张、成熟、衰退，还是周期反转？

### 4.4 护城河验证

护城河不能只写名词。每个护城河必须有证据和反证。

| 护城河类型 | 正向证据 | 反证信号 |
| --- | --- | --- |
| 品牌 | 提价能力、复购、用户主动搜索 | 靠补贴维持销量 |
| 网络效应 | 新用户提升老用户价值 | 用户多但变现弱、迁移容易 |
| 规模经济 | 单位成本下降、利润率提升 | 规模扩大但利润率下降 |
| 转换成本 | 客户迁移有真实损失 | 用户随价格/补贴迁移 |
| 成本优势 | 结构性低成本 | 竞争对手补贴即可追平 |
| 牌照/监管 | 稀缺资质、合规壁垒 | 政策变化使壁垒消失 |
| 数据/算法 | 明确提高转化率、风控或效率 | 算法无法防止竞争侵蚀 |

报告必须写：

- 护城河来源
- 护城河证据
- 护城河正在增强还是减弱
- 哪些数据会证明护城河不存在

### 4.5 财务质量

必须拆三张表。

#### 利润表

- 收入增长是否稳定？
- 毛利率是否稳定或改善？
- 销售、研发、管理费用率是否合理？
- 利润增长是否快于收入？
- 是否有一次性收益、投资收益、汇兑、会计调整？

#### 资产负债表

- 现金和净现金水平。
- 有息负债。
- 应收、存货、预付款是否异常。
- 商誉和无形资产是否有减值风险。
- 投资资产是否会带来利润波动。

#### 现金流量表

- 经营现金流是否覆盖净利润？
- 自由现金流是否稳定？
- 资本开支是维护性还是成长性？
- 股权激励是否稀释股东。
- 回购是否真正减少股本。

关键判断：

```text
好利润 = 能转成现金、能持续、需要较少新增资本、不会被少数股东/员工/债权人拿走。
```

### 4.6 管理层和资本配置

必须看：

- 管理层过去说过什么，后来兑现了吗？
- 分红、回购、并购、再投资是否理性？
- 回购是在低估时增厚每股价值，还是高位维护股价？
- 股权激励是否过度稀释？
- 是否长期主义，还是用叙事遮盖短期问题？
- 大额现金是否有清晰用途？

资本配置结论要分四类：

- 股东友好
- 中性
- 不透明
- 损害股东

### 4.7 核心假设

最后把基本面压缩成 1-3 个核心假设。

每个假设必须有：

- 正向证据
- 反证指标
- 跟踪频率
- 失效条件

示例：

```text
核心假设：广告业务仍能靠 AI 定向和视频号库存维持高于行业的增长。
正向证据：营销服务收入增速、广告主 ROI、视频号时长。
反证指标：连续两个季度广告收入增速低于行业或毛利率下降。
失效条件：广告增长靠加载率强拉但用户时长下降。
```

## 5. 估值与安全边际主线

估值不是“给目标价”，而是把故事转成数字。

### 5.1 先反推隐含预期

必须先问：

- 当前市值对应多少收入、利润、自由现金流？
- 当前 PE / FCF yield / EV/EBITDA / PS 在历史和同行中处于哪里？
- 当前价格要求未来 3-5 年收入、利润率、资本开支做到什么？
- 哪个假设一旦错，估值就塌？

### 5.2 再选估值方法

| 公司类型 | 主方法 | 辅方法 |
| --- | --- | --- |
| 成熟现金流公司 | FCF yield / DCF / PE | 分红回购收益率 |
| 高质量成长公司 | 情景 DCF / PEG / EV/Sales 到利润转化 | 同行和历史估值 |
| 平台公司 | 分部估值 / 利润倍数 / 用户变现 | 网络效应和监管折价 |
| 周期公司 | 周期平均利润 / PB | 供需周期 |
| 金融公司 | PB-ROE / 分红 | 资产质量 |
| 资产型公司 | NAV / 清算价值 | 折价率 |
| 亏损成长公司 | 单位经济模型 / 现金消耗 | 现金 runway |

### 5.3 三情景估值

任何报告必须有三情景：

- 悲观情景：核心假设不成立，可能亏多少。
- 中性情景：合理经营下的价格区间。
- 乐观情景：需要哪些条件同时成立。

不能只写乐观目标价。

### 5.4 安全边际判断

安全边际必须说明来源：

- 低估值
- 净现金
- 资产折价
- 稳定自由现金流
- 周期底部
- 回购分红
- 组合仓位足够小

也必须说明安全边际不足在哪里：

- 利润正在下滑
- 现金不回报股东
- 资本开支上升
- 监管尾部风险
- 商业模式未验证
- 估值依赖远期增长

### 5.5 价格纪律

必须给五个价格区间：

- 观察价：开始跟踪。
- 初买价：小仓试探。
- 重买价：安全边际足够。
- 停止买入价：赔率不够。
- 减仓价：未来收益率不足或估值过高。

价格区间必须绑定条件，不能只给数字。

## 6. 技术分析与市场行为主线

技术分析不预测长期价值，只服务执行。

### 6.1 道氏理论：趋势先于动作

必须判断：

- 长期趋势：上升、下降、震荡。
- 中期趋势：是否与长期一致。
- 短期趋势：是否只是反弹或回调。

结论不能只写“接近低位”。要写：

```text
长期趋势：
中期趋势：
短期趋势：
趋势是否共振：
```

### 6.2 均线和结构

看：

- 20 日、50 日、200 日均线。
- 股价在均线之上还是之下。
- 均线斜率向上还是向下。
- 是否站回关键均线。
- 是否形成更高高点/更高低点，或更低高点/更低低点。

### 6.3 成交量和量价关系

看：

- 下跌是否放量。
- 反弹是否缩量。
- 突破是否有量确认。
- 跌破支撑是否伴随放量。
- 是否存在明显机构抛售或吸筹痕迹。

### 6.4 动量和超买超卖

可用：

- RSI
- MACD
- 相对强弱：相对大盘、行业、竞品。
- 52 周位置。

注意：超卖不等于该买，超买不等于该卖。它只说明短期风险收益。

### 6.5 支撑、压力和事件窗口

必须写：

- 最近支撑位。
- 跌破后下一支撑。
- 第一压力位。
- 中期压力位。
- 即将发生的财报、监管、产品、宏观事件。

### 6.6 技术面输出

技术面最终只给执行建议：

- 现在买
- 等回调
- 等突破
- 分批
- 只观察
- 不追
- 跌破某价位暂停

不能写“技术形态好，所以买入”。

## 7. 宏观、周期和风格主线

宏观不是用来预测股价，而是校正估值和仓位。

### 7.1 利率和折现率

看：

- 无风险利率。
- 美债收益率。
- 实际利率。
- 流动性环境。
- 汇率。

影响：

- 利率上行压制长久期成长股估值。
- 利率下行利好长久期资产和债券。
- 汇率影响海外资产和中概股人民币回报。

### 7.2 经济周期

判断当前行业依赖：

- 消费周期
- 广告周期
- 房地产周期
- 信贷周期
- 科技资本开支周期
- 商品周期

### 7.3 风格周期

看市场当前偏好：

- 成长 vs 价值
- 大盘 vs 小盘
- 高股息 vs 高弹性
- 国内资产 vs 海外资产
- AI/科技主题 vs 防守资产

风格顺风不能替代基本面；风格逆风也不等于公司坏。

## 8. 其他有价值流派

### 8.1 质量投资

核心看：

- 高 ROIC
- 稳定毛利率
- 低资本开支
- 高自由现金流
- 可持续再投资
- 管理层资本配置

输出：

```text
质量等级：优秀 / 合格 / 普通 / 差
质量缺陷：
```

### 8.2 成长投资

核心看：

- TAM 是否真实。
- 渗透率处在哪个阶段。
- 增长来自用户、价格、频次、品类，还是并购。
- 增长是否伴随利润率改善。
- 单位经济模型是否成立。

成长股最怕：

- 增长来自补贴。
- 增长越快亏损越大。
- TAM 大但竞争者拿走利润。

### 8.3 GARP：合理价格买成长

适合：

- 仍有增长，但估值已不便宜的公司。

看：

- 增速和估值是否匹配。
- PEG 只是粗筛，不能替代现金流。
- 增长质量比增长速度重要。

### 8.4 质量价值

适合：

- 好公司短期被误解。
- 盈利暂时承压但护城河未变。
- 市场把周期性问题当永久问题。

关键：

- 必须证明问题是暂时的。
- 必须写清恢复路径。

### 8.5 逆向投资

逆向不是和市场唱反调。

必须满足：

- 市场共识明显悲观。
- 悲观逻辑被充分定价。
- 你有明确证据证明悲观过度。
- 仓位能承受继续下跌。

### 8.6 事件驱动

适用：

- 回购
- 分拆
- 监管落地
- 资产出售
- 管理层变化
- 产品周期
- 财报拐点

事件驱动必须写：

- 事件是什么。
- 时间窗口。
- 市场预期。
- 超预期点。
- 如果事件落空怎么办。

### 8.7 行为金融

必须检查：

- 是否因为已持有而找理由。
- 是否因为亏损不愿承认错误。
- 是否因为低 PE 锚定为便宜。
- 是否因为跌多了觉得安全。
- 是否因为熟悉公司而高估确定性。
- 是否因为最近新闻而过度反应。

报告必须有一段：

```text
我可能在哪些地方自我欺骗？
```

## 9. 组合和仓位主线

### 9.1 先看风险桶

标的必须归入风险桶：

- A股核心权益
- 全球核心权益
- 中国互联网/平台经济
- 高股息/红利
- 消费
- 科技成长
- 黄金
- 债券/现金
- 行业主题

不能只看单票。

### 9.2 仓位上限

必须根据四件事定仓位：

- 标的质量
- 估值安全边际
- 组合中相关资产暴露
- 用户现金流和风险承受能力

默认约束：

- 新公司初始仓位 1%-3%。
- 高确定性核心标的 5%-8%。
- 单票上限通常不超过 10%。
- 同一风险桶一般不超过长期投资资金 15%-25%，具体看资产类别。

### 9.3 分批规则

买入不能只写“可以买”。

必须写：

- 第一笔买多少。
- 什么价格或事件加第二笔。
- 什么情况暂停。
- 什么情况承认错误。
- 什么情况卖出。

## 10. 反方审查

反方审查必须从四类反驳开始：

1. **事实反驳**：数据是否错、口径是否错、是否过时。
2. **逻辑反驳**：增长、护城河、估值之间是否断裂。
3. **激励反驳**：管理层、商家、客户、监管者的激励是否相反。
4. **市场反驳**：低估值是否有合理原因，市场是否知道你知道的东西。

必须输出：

- 最强反方观点。
- 最可能错在哪里。
- 需要补的证据。
- 哪些信号出现后必须推翻原结论。

## 11. 最终结论模板

最终结论不能只写“观察”。

必须写：

```text
结论：买入 / 加仓 / 持有 / 减仓 / 卖出 / 观察 / 暂不判断
判断等级：强 / 中 / 弱 / 信息不足
现在动作：
第一笔仓位：
加仓条件：
暂停条件：
减仓条件：
失效条件：
下次复盘时间：
最重要跟踪指标：
```

## 12. 报告质量自检

报告写完后必须自检：

- 有没有把公司介绍当成投资分析？
- 有没有把好公司等同于好股票？
