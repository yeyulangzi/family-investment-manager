# 15-基金与产品穿透Agent — 基金深度研究

> 调用时机：SKILL.md 意图 = 研究-基金/ETF。
> **数据优先 ttskill（天天基金 SQL）→ AKShare → 网页搜索。关键数据双源验证。**
> 不只分析基金本身——要回答五个问题：好不好？现在买？买多少？配不配我？重不重叠？

## 数据获取

| 优先级 | 数据源 | 取什么 |
|:--:|------|------|
| 1 | **ttskill** | 基金净值/持仓/费率/经理/规模/历史业绩/基准/最大回撤 |
| 2 | AKShare | A 股 ETF 列表/净值 |
| 3 | 网页搜索 | 降级补充 |

> ttskill 常用命令：`ACCOUNT_HOLDING`（我的持仓）、`FUND_INFO`（基金详情）、`FUND_HOLDINGS`（底层持仓）、`FUND_NAV`（净值历史）、`INDEX_INFO`（指数估值分位）

## 一、基金质量（好不好？）

### 1. 基本信息
- 名称 / 代码 / 类型 / 成立时间 / 规模 / 综合费率
- 基金经理：任职时间、从业年限、历史产品业绩

### 2. 策略识别
- 大盘/小盘？价值/成长/均衡？主动/被动/指增？
- 基准指数 + 跟踪方式
- 换手率 + 规模是否限制策略

### 3. 业绩质量
| 指标 | 1年 | 3年 | 5年 | vs 基准 |
|------|:--:|:--:|:--:|:--:|
| 累计收益 | | | | |
| 年化收益 | | | | |
| 最大回撤 | | | | |
| 夏普比率 | | | | |

- 超额来源：选股？行业配置？市场 Beta？运气？
- 牛熊表现：跟涨 vs 抗跌
- 业绩一致性：持续好 vs 靠某一年

### 4. 经理评估
- 从业 < 3 年 → 标注「经验不足」
- 是否经历完整牛熊？
- 管理规模变化：流量驱动 vs 能力驱动？

### 5. 费率
- vs 同类中位数。1% 差异 × 20 年 = 终值差 20%+

## 二、底层资产穿透（钱到底投了哪？）

### 1. 持仓拆解
- 前十大持仓 + 占比
- 行业分布（单一行业 > 30% 标注）
- 个股集中度（前十大 > 50% 标注）

### 2. 资产类别映射
- 穿透到底层属于什么资产类别：A 股/港股/美股/债券/黄金/现金
- 和 IPS 中哪一类对应？

### 3. 行业基金联动
- 如果是行业/主题基金 → **联动 `17-行业研究Agent`**，判断行业前景和估值分位
- 如果是宽基 → **联动 `02-大类资产配置Agent`**，判断该资产类别当前估值分位

---

## 三、买入时机（现在值不值得买？）

### 1. 底层资产估值
- 穿透后主要暴露的指数/资产当前 PE/PB 历史分位
- 用 ttskill `INDEX_INFO` 查指数估值
- 判断：低估/合理/高估？

### 2. 时机结论
- 当前适合：一次性买 / 分批买 / 定投 / 等待 / 不适合
- 理由：基于估值分位 + 行业景气度（如联动了行业 Agent）

---

## 四、仓位建议（买多少？）

### 1. 与 IPS 对齐
- 该基金映射的资产类别在 IPS 中的目标比例
- 当前该类别实际比例及偏离
- 本次买入后是否会超配？

### 2. 仓位上限
- 单只基金 ≤ 金融资产 10%
- 同类基金合计 ≤ 该类资产 IPS 目标 + 5%
- 不因买入让现金跌破 100 万硬底线

### 3. 执行建议
- 建议仓位：占金融资产 X%（金额 Y 元）
- 分批节奏：一次性 / 2-3 批 / 定投
- **必须写「不做什么」**

---

## 五、个人适配（配不配我？）

- IPS 中该资产类别是否低配？（低配 → 优先级高）
- 风险桶：该基金属于哪个风险桶？桶里还有多少空间？
- 收入空窗期约束：不将应急缓冲投入权益
- 如已有同类持仓 → 进入重叠分析

---

## 六、组合重叠分析（重不重叠？）

### 与已有持仓对比
```
┌─ 和 XXX 基金：持仓重叠 X/10，行业重叠 X% → ✅/⚠️/🔴
├─ 和 YYY 基金：风险因子重叠（大盘成长 + A 股）→ ⚠️ 分散不足
└─ 总体：该基金对组合的边际分散贡献 = 大/中/小/负
```

重叠 > 40% → 标注「分散效果有限，实质是加仓而非分散」
