# 05-技术与市场行为Agent — 行业定制化交易系统

> 技术面不构成买入理由。技术面回答三个问题：
> ① 当前处于什么状态？（趋势/震荡/转折）
> ② 供需力量在谁手里？（买方主导/卖方主导/均衡）
> ③ 如果错了，在哪认错？（止损位置）

## 0. 前置：股票分类（第一步，5 秒完成）

**选错系统的代价 > 选错个股**。周期股用成长股系统 → 买在利润顶峰。消费股用周期系统 → 反复止损。

| 类型 | 本质特征 | 适用系统 | 选错后果 |
|------|------|------|------|
| **周期制造** | 利润由产品价格驱动，PB 大幅波动 | 系统一 | 均线金叉 = 买在利润顶峰 → 腰斩 |
| **成长股** | 收入增速 > 20%，EPS 加速，渗透率 < 50% | 系统二 | 左侧抄底 = 接飞刀，亏损无底 |
| **品牌消费** | ROE > 15% 且稳定，经营史 > 10 年 | 系统三 | 追突破 = 买在回归均线的起点 |
| **金融** | PB < 2，利润由利差/保费/成交驱动 | 系统四 | 趋势跟随 = 在 PB 区间里来回割 |
| **高股息防御** | 股息率 > 3%，低 Beta，公用事业/电信 | 系统五 | 动量策略 = 完全失效 |
| **主题炒作** | 概念驱动，无业绩 | **跳过** | 参与 = 赌博 |

## 通用工具箱

> 以下工具是所有五个系统的基础砖块。每个工具给出「最常被误解的点」——大部分散户止损在这些误解上。

### 工具一：Wyckoff 市场结构（最底层框架）

Wyckoff 不只是一个"吸筹/派发"模板。他的核心是**用价格和成交量的关系来推断"Composite Operator"（聪明钱）在做什么**。

#### 1.1 三定律（所有分析的基础）

```
定律一（供需）：价格涨 = 需求 > 供给。价格跌 = 供给 > 需求。
  → 不要在"成交量萎缩、价格窄幅震荡"的时候判断方向——供需均衡，无方向。

定律二（因果）：一段趋势的幅度，由之前的"因"（吸筹/派发区间的长度）决定。
  → 横盘 3 天就突破 = 原因太小 → 大概率假突破。横盘 3 个月再突破 = 原因大 → 大概率真趋势。

定律三（努力 vs 结果）：
  成交量（努力）vs 价格变动（结果）的关系：
  ├─ 放量 + 大阳线 = 努力有结果，买方意愿强 → 看涨
  ├─ 放量 + 小阳线(窄幅) = 努力无结果，有人在供应 → ⚠️ 警惕
  ├─ 缩量 + 大阳线 = 几乎没有努力但有结果 → 供应枯竭 → 看涨
  ├─ 放量 + 大阴线 = 努力有结果，卖方强 → 看跌
  ├─ 缩量 + 大阴线 = 几乎没有努力但有结果 → 买方缺席 → 看跌
  └─ 放量 + 小阴线(窄幅) = 努力无结果，有人在吸收 → 潜在底部
```

#### 1.2 吸筹模板（完整版，不只是 SC/ST/SOS）

```
阶段 A：下跌停止
  PS（初步支撑）：放量，长下影，首次出现大量买盘
  SC（恐慌抛售）：巨量 + 宽幅下跌 + 收盘远离低点（长下影）
  → SC 之后的反弹高点 = 初步阻力（IC）

阶段 B：构建因
  ST（二次测试）：缩量回到 SC 低点附近，不破或微破 → 供应枯竭
  → 有时有多次 ST。每次缩量 = 供应在减少
  → 此阶段可能持续数周到数月

阶段 C：弹簧
  Spring（弹簧/震仓）：瞬间跌破交易区间下沿后快速收回，放量
  → 目的是让最后的弱手卖出
  → 弹簧是最佳买入机会，但也是假信号最多的地方
  
阶段 D：趋势启动
  SOS（强势信号）：放量突破交易区间上沿
  LPS（最后支撑点）：突破后缩量回踩区间上沿（原阻力变支撑）
  → LPS 是加仓位置，比 SOS 更安全

阶段 E：趋势
  价格上涨，回调缩量，上涨放量。

⚠️ 失败模式：
  Spring 后放量跌破 SC 低点 → 不是吸筹，是在继续派发。前面的分析全错。
  SOS 当天放量但次日就阴线反包 → 假突破。回到区间内。
  SOS 后回踩 LPS 时放量跌 → 不是回踩，是又一轮下跌。
```

#### 1.3 派发模板（镜像）

```
阶段 A：上涨停止（PSY 初步供应 → BC 购买高潮）
阶段 B：构建因（ST 二次测试高点，缩量不破 → 需求枯竭）
阶段 C：UTAD（向上突破失败/假突破）
阶段 D：SOW（弱势信号/跌破区间）
阶段 E：下跌趋势
```

### 工具二：DeMark TD Sequential + TD Combo（完整版）

> 当前版本只写了计数规则，这是 DeMark 工作中最浅的一层。真正有价值的是 qualifier（限定条件）——90% 的 TD9 信号没有 qualifier 确认，不值得交易。

#### 2.1 TD Setup 的隐藏规则（大部分人不知道）

```
Setup 完成条件（仅计数不够）：
  ├─ 第 8 根或第 9 根 K 线的最低点 < 第 6 根和第 7 根的最低点（上涨结构）
  │   → 如果第 9 根的低点高于第 6/7 根 → Setup 不完美，降低信度
  ├─ 第 9 根的收盘价 > 第 8 根的收盘价（上涨结构）→ Setup 完成
  └─ 完美 Setup（9 根依次满足，没有任何中断）> 不完美 Setup

Countdown 的隐藏规则：
  ├─ Countdown 第 13 根收盘价 ≥ 第 8 根收盘价（上涨结构）
  ├─ Countdown 第 13 根必须 > Setup 第 9 根的最高价（上涨结构）
  │   → 如果不满足 → Countdown 失效，用 Setup 9 的价格做参考
  └─ Countdown 可以跨 K 线（不是连续的），但 13 步必须在 Setup 完成后
      的 TD 容忍区间内完成。超时 → 失效

TD Combo（Countdown 的升级版）：
  比 Sequential 更严格。Combo 有三阶段，每阶段有独立计数规则。
  如果 Sequential 和 Combo 同时给出信号 → 强信号。
  如果只有 Sequential → 中等信号。如果只有 Combo → 弱信号（等待确认）。
```

#### 2.2 A 股各类型的 TD 信号可靠性（基于市场共识，非精确回测）

| 类型 | 日线 | 周线 | 月线 | 最佳用法 |
|------|:--:|:--:|:--:|------|
| 周期股 | 50-60%（假信号多）| 65-75%（比较可靠）| 70-80%（罕见但信号强）| 周线 9 + PB 极端 |
| 成长股 | <40%（假信号极多）| 45-55% | 少样本 | 仅用周线下跌 9，上涨 9 忽略 |
| 消费股 | 45-55% | 60-70%（均线附近最强）| 少样本 | 周线 9 + 均线回归 |
| 金融股 | <35%（基本无效）| 40-50% | 50-60% | 仅周线极端值 |
| 高股息 | 40-50% | 50-60% | 少样本 | 仅供参考 |

> ⚠️ 上表不是精确回测数字。A 股历史较短（多数指数只有 15-30 年），样本量不足以得出统计显著的结论。上表是市场实践中的共识经验。**任何声称"TD9 准确率 85%"的说法都是胡扯。**

#### 2.3 TD9 最大的坑：趋势中的连续信号

```
单边上涨中，TD 上涨 9 会连续出现。第一个 9 后价格继续涨 → 第二个 9 → 第三个 9。
→ 2014-2015 年 A 股牛市中，券商股连续出现 4 个周线 TD 上涨 9。
→ 如果在第一个 9 就卖空 → 错失整个牛市。
→ 如果在第三个 9 还追 → 买在最高点。

正确用法：
  ├─ 第一个 9 → 减仓 1/3（不是全卖）
  ├─ 第二个 9 + 周线 MACD 顶背离确认 → 再减 1/3
  ├─ 第三个 9 + 放量反转 K 线 → 清仓
  └─ 任何 9 完成 + K 线反包确认 → 可以提前执行
```

### 工具三：MACD 的底层逻辑（不只是金叉死叉）

#### 3.1 MACD 在数学上是什么

```
MACD = 12EMA - 26EMA → 短期趋势动能减去长期趋势动能
Signal = 9EMA of MACD → MACD 的平滑
Histogram = MACD - Signal → 动能的加速度

换句话说：
  MACD 线 = 价格的"速度"（一阶导数）
  Histogram = 价格的"加速度"（二阶导数）
  Signal 交叉 = 加速度改变方向的那一刻

→ MACD 金叉 ≠ 价格要涨。MACD 金叉 = 短期趋势正在加速上涨，或者正在从下跌转为不跌。
→ MACD 死叉 ≠ 价格要跌。MACD 死叉 = 短期趋势正在加速下跌，或者从上涨转为不涨。
```

#### 3.2 零轴的真实含义

```
零轴 = 12EMA 与 26EMA 相交的地方 = 短期趋势与长期趋势力量均等

零轴上方金叉 → 趋势向上，回调结束 → 顺势，安全
零轴下方金叉 → 趋势向下，反弹 → 逆势，只能轻仓
零轴上方死叉 → 趋势向上，正常回调 → 不一定是卖点
零轴下方死叉 → 趋势向下，加速下跌 → 最危险，绝不碰

→ 只做零轴上方的金叉。零轴下方的金叉 = 等它上了零轴再说。
→ 这条规则过滤掉了 > 50% 的假信号。
```

#### 3.3 背离的正确使用（最容易被滥用的信号）

```
背离不是反转信号。背离是动量衰竭信号。

动量衰竭 + 趋势线突破 = 反转可能开始
动量衰竭 + 趋势线完好 = 趋势只是在休息

⚠️ 经典错误：看到底背离就买 → 价格继续跌 20% → 止损 → 然后再涨
原因：底背离告诉你卖方力量在减弱，但没告诉你买方力量在增强。
      弱势股可以在底背离后继续阴跌数月。

→ 底背离必须 + 放量阳线确认（量 > 20 日均量 × 1.5）
→ 顶背离必须 + K 线反转确认（吞没/黄昏之星/长上影）
→ 没有确认 = 信号不成立，不做
```

### 工具四：成交量与 VSA（成交量价差分析）

#### 4.1 成交量的核心问题

```
不看绝对量，看"量和价的配合"

关键观察：
  ├─ 上涨时：量应该放大。如果缩量上涨 → 需求不足，可能回落。
  ├─ 下跌时：量应该缩小。如果放量下跌 → 供给充足，还会跌。
  ├─ 突破时：量必须放大（> 20 日均量 × 1.5）。缩量突破 → 假突破概率 > 60%。
  └─ 调整时：量应该持续萎缩。量在调整末端萎缩到高点的 20-30% → 调整接近尾声。

阴线量 vs 阳线量：
  如果连续 5 天阴线量 > 阳线量 → 供给主导
  如果连续 5 天阳线量 > 阴线量 → 需求主导
```

#### 4.2 三个最常见的量价陷阱

```
陷阱一：底部放量 ≠ 反转
  底部放量可能是：
    a) 恐慌盘最后抛出 + 聪明钱接盘（真底）
    b) 抄底资金涌入 + 套牢盘全扔给他们（反弹后继续跌）
  
  区分方法：观察放量后的回踩是否缩量。
    → 缩量回踩 + 不破放量日低点 = a
    → 继续放量 + 跌破放量日低点 = b

陷阱二：缩量调整 ≠ 健康
  缩量调整在牛市中健康。在熊市中可能意味着无人接盘。
  区分方法：看调整结束后的反弹量。如果放量反弹 = 健康。如果继续缩量 = 不健康。

陷阱三：天量天价 ≠ 立即见顶
  天量可以持续多日（尤其是在主升浪中）。
  天量 + 长上影线 + 收盘在日内中部以下 = 短期见顶信号
  天量 + 实体阳线 + 收盘在日内高点 = 趋势加速，不是见顶
```

## 系统一：周期制造 — 产品价格领先 + PB 锚 + 威科夫 + 九转

> **核心矛盾**：周期股最好的买入时机，是所有公开信息最难看的时候。产品价格底部 + PB 历史低位 + 全市场都在说"这次不一样，行业完蛋了"。周期股最差的买入时机，是券商开始出"买入"评级、路边社都在讨论涨价的时候。
>
> 上一版的问题：缺少产品价格领先关系的量化、缺少周期股失败模式、缺少历史参考案例。

### 1.1 识别真正的领先关系

周期股的分析起点永远是**明确产品价格**。不是"行业景气度"——景气度太模糊，必须是具体产品报价。

```
每只周期股必须映射到 1-2 个具体产品价格：
  存储芯片 → DRAM DDR4 8Gb 现货价 / NAND 256Gb TLC 合约价
  面板     → 32 寸 / 55 寸 LCD 面板均价（WitsView/Omdia 每周发布）
  航运     → SCFI（上海出口集装箱运价指数）/ BDI（波罗的海干散货）
  碳酸锂   → 电池级碳酸锂现货价（上海有色网 SMM）
  钢铁     → 螺纹钢期货主力合约 / 热轧板卷
  猪肉     → 22 省市生猪均价 / 生猪期货
  石油     → Brent / WTI 原油期货
  煤炭     → 秦皇岛 5500 大卡动力煤

产品价格领先股价的时间差（经验规律，非精确）：
  航运：SCFI 领先集运股 1-2 周（几乎同步）
  存储：DRAM 合约价领先存储股 2-3 个月
  面板：面板价格领先面板股 1-2 个月
  锂矿：碳酸锂现货领先锂矿股 1-3 个月（但股价常提前抢跑，领先关系不稳定）
  猪肉：猪价领先养猪股 2-4 个月（但能繁母猪存栏是更领先的指标，领先猪价 10 个月）
```

### 1.2 五条件买点体系（不是三条件，三条件太宽松）

```
强买点（五个条件全部满足）→ 可以重仓：

① PB ≤ 近 5 年 20% 分位值（不是随便一个低 PB）
   → 为什么 20% 不是 10%？因为 10% 分位可能还没跌完，而且机会太少。
   → 近 5 年 = 至少包含一个完整周期。如果近 5 年是单边下跌（没周期）→ 用近 10 年。

② 核心产品价格出现底部结构
   → 不是"不创新低"——那可能是横盘。底部结构 = 至少出现过一次从低点反弹 > 10%。
   → 更可靠的是：产品价格形成更高的低点（回调不破前低）。

③ 周线 TD 下跌 Setup 9 完成（最好有 Countdown 13）
   → 9 是必要条件。9 + 13 是加分项。
   → 完美 Setup（9 根依次满足，无中断）> 不完美 Setup。

④ 威科夫吸筹模板至少完成到阶段 C（Spring）
   → 必须看到 SC（恐慌抛售）+ ST（缩量测试）+ Spring（震仓）。
   → 如果只有 PB 低 + TD 9 但没有威科夫结构 → 可以买，但必须轻仓。

⑤ 产品价格与股价出现背离：价格企稳反弹 > 10%，但股价还在底部磨
   → 这可能是最好的信号——基本面已经改善，市场还没反应过来。
   → 没有背离也可以买，但有背离可以重仓。

→ 五条件全满足 = 重仓。满足 ①② + ③④⑤ 中至少 1 个 = 首仓。只满足 ① = 等。
```

### 1.3 四个"绝对不买"（比买点更重要）

```
绝对不买 1：产品价格还在加速下跌
  即使 PB 已经在 10% 分位。加速下跌的产品价格 = 再便宜也不买。
  这是周期股亏钱第一原因："PB 很便宜了" → 买入 → 产品价格继续崩 → PB 从 10% 分位跌到 5% → 腰斩。
  加速下跌的定义：周线连续 3 周跌幅 > 5%，或者月线跌幅 > 15%。

绝对不买 2：行业还在产能扩张
  即使产品价格企稳。如果龙头企业还在大规模扩产 → 供给还会增加 → 价格反弹是暂时的。
  查：龙头公司最新财报中 CAPEX 计划。如果 CAPEX/收入 > 15% 且趋势向上 → 危险。

绝对不买 3：没有明确的产品价格锚
  如果说不清这个周期股的核心产品价格是什么、去哪查 → 你不理解它的周期驱动 → 不碰。

绝对不买 4：PB 极端低但 ROE 持续为负
  PB 低 + ROE < 0 = 价值陷阱。公司在亏损，净资产在缩水 → PB 低是合理的。
  周期底部的 ROE 可以短暂为负（1-2 季度），但如果连续 4 季度亏损 → 避开。
```

### 1.4 历史参考案例（真实市场事件）

```
案例 1：2016 年钢铁供给改革
  信号：2015 年底螺纹钢期货跌破 1600 元/吨（全行业亏损）
        + PB 全线 < 0.8 + 政策提出"供给侧改革"
  结果：2016 年钢铁股涨幅 50-100%，螺纹钢反弹至 3000+
  教训：周期股的大底往往伴随政策干预——不是坏事，是催化剂。

案例 2：2020 年航运超级周期
  信号：2020 Q2 SCFI 从 800 飙升至 2000+（疫情后补库 + 运力紧张）
        + 中远海控 PB < 1
  结果：中远海控 2020.06-2021.07 涨幅 > 500%
  教训：这种级别的周期不常见。不要每次运价涨就以为是下一个 2020。
        "这次不一样"通常会一样——2022 后运价回归，中远海控跌超 50%。

案例 3：2023 年存储芯片周期
  信号：2023 Q1 DRAM 价格还在跌（PB 低但不买）
        2023 Q3 DRAM 价格企稳 + PB 极低 + AI 需求预期
  结果：兆易创新等涨幅 70-100%
  教训：Q1 不买是对的。等产品价格真的企稳再买——可能错过底部 10-15%，但不会腰斩。
```

### 1.5 系统一的失败模式

```
模式 A：产品价格反弹是短期补库脉冲，不是周期反转
  这是最常见的假信号。下游补库 2-3 个月 → 价格涨 → 买入 → 补库结束 → 价格跌回。
  → 防御：确认产品价格企稳 > 2 个月 + 下游需求（不是库存）在增长。

模式 B：PB 低是因为净资产被高估（商誉/存货虚高）
  周期股在底部时财报藏雷——商誉没减、存货没提减值。
  → 防御：用 PB（扣除商誉）+ 检查存货周转天数是否异常延长。

模式 C：结构性衰退被当成周期性底部
  煤炭在碳中和背景下、传统媒体在互联网冲击下——是结构性衰退，不是周期下行。
  "PB 很低"→ 买了 → 等 5 年也不涨。
  → 防御：问自己"10 年后这个产品还存在吗？需求还会增长吗？"
```

## 系统二：成长股 — VCP + CANSLIM + Weinstein + 止损铁律

> **核心矛盾**：成长股投资中，技术面比基本面更重要。不是因为技术能预测涨跌——是因为成长股的唯一确定性是"如果趋势坏了，你必须走"。PE 从 80 跌到 40，你觉得便宜了 → 抄底 → PE 继续跌到 20 → 腰斩。成长股没有估值的锚——它的锚是趋势。
>
> 上一版的问题：每个方法都提到了，但都只给了最浅的规则。缺少方法的完整版本、缺少 A 股适配、缺少假突破识别。

### 2.1 Mark Minervini 的完整 VCP 模板（不只是"收缩 > 2 波"）

```
Minervini 的 Specific Entry Point (SEP) 体系：

VCP 的前置条件（不满足 = 不用 VCP 分析）：
  ├─ 股价必须 > 200 日均线，且 200 日线向上
  ├─ 150 日均线 > 200 日均线（中长期趋势向上确认）
  ├─ 50 日均线 > 150 日均线
  ├─ 当前股价 > 50 日均线
  ├─ 相对强度 RS > 70（最好 > 80）
  └─ 以上全部满足 = "趋势模板"通过。缺任何一条 → 不用 VCP，不买。

VCP 本身的评判标准（不是"感觉"是"测量"）：
  ① 收缩波数：2-4 波。1 波太少（没有充分调整），5 波以上太弱（反复磨蹭）。
  ② 振幅递减：每波的振幅 < 前一波的 75%。用"波峰到波谷的百分比"测量。
     例：第一波回撤 25%，第二波回撤 18%（18/25=72%→满足），第三波 10%。
  ③ 成交量递减：每波的顶点量 < 前波顶点量。每波的谷底量 < 前波谷底量。
     如果收缩过程中突然出现放量（> 前波顶点量）→ 谨慎，可能不是 VCP。
  ④ 底部抬高：每一波的低点 > 前一波的低点。> 前波低点至少 1%。
     如果某波低点低于前波 → VCP 结构破坏，重新计数。
  ⑤ 收缩末端：最后一波的幅度通常最小（< 10%），成交量萎缩到最低。
     → 这时就是"暴风雨前的宁静"。

Pivot Point（枢轴点）= 整个 VCP 结构的最高点（通常是第一波的高点）
  SEP = Pivot Point + 0.10（在这个价格 + 0.10 买入）
  突破日成交量必须 > 50 日均量 × 1.5。不是 1.5 → 假突破概率高。

VCP 失败的最常见原因：
  ① 大市不好（CANSLIM 的 M = Market direction 是最重要的字母）
  ② EPS 增速在放缓（表面看 VCP 完美，但基本面的动量没了）
  ③ 突破后第 2-3 天缩量回落 → "买盘不能持续"
```

### 2.2 Minervini 的止损纪律（比他写的任何买点规则都重要）

```
这是他整个系统中最核心的部分。他反复说："你可以在只有 40% 胜率的情况下赚钱，
只要你的平均盈利是平均亏损的 3 倍。"

Minervini 止损规则（不是建议，是规则）：
  ├─ 任何单笔交易亏损不超过 7-8%。到达 → 立即卖，不问原因。
  ├─ 加仓后如果整体成本亏损 > 5% → 减半仓（加仓失败 = 你的买点有问题）。
  ├─ 如果连续 3 笔交易止损 → 暂停交易 2 周。做错了 3 次 = 你现在看不懂市场。
  ├─ 如果某只股票从高点回撤 > 15% → 清仓。趋势可能已经变了。
  └─ 如果买入后 3 周内没有盈利 → 卖出。"好股票不会让你等太久。"

与 A 股的适配调整：
  A 股成长股波动更大。7-8% 止损可能太紧（容易被洗）。
  → 调整：单笔止损放宽到 10%，但仓位相应减少（Kelly 公式调整）。
  → 或者：用 ATR 设止损，2 倍 ATR 为止损距离（自适应波动率）。
```

### 2.3 Stan Weinstein 阶段分析（比均线金叉有用 10 倍）

```
Weinstein 用 30 周均线（150 日均线）的斜率和股价位置分四阶段：

第一阶段（底部）：股价在 30 周均线上下来回穿越，30 周均线走平
  → 特征：成交量萎缩，价格波动收窄。像 "弹簧被压紧"。
  → 操作：观察，记录。不买。因为不知道要磨多久。

第二阶段（上涨）：股价在 30 周均线上方，均线向上，股价持续创新高
  → 特征：上涨放量，回调缩量。每次回调到 30 周均线是买点（不是每次都能碰到）。
  → 操作：这是唯一可以买入和持有的阶段。只在第二阶段买成长股。

第三阶段（顶部）：30 周均线走平，股价围绕均线上下震荡
  → 特征：成交量不规则，经常出现上影线。波动率收窄。
  → 操作：只卖不买。可以减仓。如果从最高点回撤 > 15% → 提前清仓。

第四阶段（下跌）：股价在 30 周均线下方，均线向下，持续创新低
  → 特征：反弹缩量，下跌放量。每次反弹到 30 周均线都被压下。
  → 操作：不持有任何处于第四阶段的股票。不抄底。不研究基本面。
         → "万一反转呢？"等它重新进入第一阶段或第二阶段再说。
```

### 2.4 CANSLIM 中 M 的实战用法（比所有其他字母都重要）

```
O'Neil 的 CANSLIM 中，M = Market Direction（市场方向）是最重要的。
他的原话："即使你其他 6 个字母全做对，M 错了，你也赚不到钱。"

判断大市方向的具体方法（不是感觉）：
  ├─ 跟踪指数（A 股：中证 500/创业板，不是上证综指）
  ├─ 指数是否在 50 日均线上方？50 日线方向？
  ├─ 过去 5 天中有多少天是 "distribution day"（放量下跌日）？
  │   → 如果过去 4-5 周内 > 5 个放量下跌日 → 大市处于压力中
  ├─ 市场领导股（最近涨最多的那些）开始回调吗？
  │   → 如果领导股开始跌幅 > 10%，而指数还没跌 → 市场内部在恶化

大市判断结论（三选一）：
  ├─ Confirmed Uptrend（确认上升）：可以买成长股
  ├─ Uptrend Under Pressure（上升压力）：减仓，不开新仓
  └─ Market in Correction（调整中）：空仓，等
```

### 2.5 系统二的失败模式

```
模式 A：假突破（VCP 突破日买入 → 第 2 天就开始跌）
  最常见原因：
    a) 突破日量 < 50 日均量 × 1.5
    b) 突破日收盘价 < 开盘价（高开低走）
    c) 大盘在调整中（M 错了）
    d) 突破前没有缩量到地量（收缩末端的量还不够小）
  
  防御：
    → 条件 a/b 触发 → 不买
    → 条件 c 触发 → 任何成长股都不买
    → 条件 d 触发 → 等一周再看

模式 B：EPS 增速放缓（季报出来后增速从 30% 降到 15%）
  即使技术面完美，也必须卖。
  成长股的核心驱动力是 EPS 加速。加速度消失 = 成长逻辑动摇。

模式 C：大盘牛市末期的成长股疯狂
  2015 年 A 股创业板、2021 年美股 SaaS——成长股在牛市末期会加速上涨。
  这时候 VCP 会越来越短、突破越来越急，感觉"每次都买对"。
  → 这是最危险的时候。越涨越买 = 越买越贵。
  → 防御：坚持在突破日买（不在突破后追），严格止损，注意大盘 distribution days 计数。
```

## 系统三：品牌消费 — 均线回归 + 股息锚 + Elder 三重滤网

> **核心矛盾**：品牌消费股的波动有"地心引力"——涨多了会回到均线，跌多了也会回到均线。这不是玄学——优质消费股的 ROE 稳定，内在价值线性增长，股价围绕内在价值波动。所以均线不是技术指标，是内在价值的近似代理。
>
> 上一版的问题：买点条件看似具体，但没有讲"为什么均线回归在消费股中有效而在周期股中无效"。

### 3.1 为什么消费股可以用均线策略（而别的股不行）

```
消费股均线回归有效的三个前提（缺一不可）：

① ROE 长期稳定（> 15%，波动 < 30%）
   → ROE 稳定意味着内在价值在按大致固定的速度增长。
   → 200 日均线 ≈ 过去一年的平均价格 ≈ 内在价值的一个近似值。
   → 如果 ROE 大幅波动（周期股），内在价值不稳定 → 均线无参考意义。

② 商业模式可预测（收入/利润波动小）
   → 白酒、调味品、乳业——消费者每天都买，需求稳定。
   → 均线回归策略在必需消费品上成功率 > 60%。在可选消费品（汽车、奢侈品）上 < 40%。

③ 有股息率做锚（提供最底部的估值参考）
   → 股息率历史分位 = 市场对这只股票的悲观程度的量化指标。
   → "股息率处于历史 90% 分位"比"PE 很低"更可靠——股息是真金白银。
```

### 3.2 Elder 三重滤网的完整用法

```
Alexander Elder 的三重滤网不是为了复杂——是为了解决"只看一个时间框架"的问题。

第一重（周线）：用 MACD 柱的方向定趋势方向
  → MACD 柱在零轴上且向上 = 只能做多
  → MACD 柱在零轴下且向下 = 只能做空（A 股不能做空 = 不参与）
  → MACD 柱在零轴下但开始向上 = 底部可能不远，但等到了零轴上再说
  ⚠️ 如果在零轴下强行做多 = 在第四阶段买股票。Elder 说这是"和新手一起亏钱"。

第二重（日线）：用震荡指标找回调买点
  → 在周线向上趋势中，等日线回调。
  → 常用指标：RSI < 40、Stochastic < 30、Force Index 负值
  → 不是"RSI 低了就买"——是"RSI 低了 + 价格到了均线附近 + 缩量"= 买

第三重（60 分钟/30 分钟）：精确入场
  → 在小时间框架上等一个"突破"信号（站上分时均线或小级别压力位）
  → 作用：避免在日线回调的半山腰进（回调可能还没结束）

三重滤网的灵魂：如果三重都同意 → 做。如果有一重不同意 → 不做。
→ 过滤掉 > 70% 的低质量信号。
```

### 3.3 四层买点体系（保留之前的结构，加深逻辑）

```
买点①：50 日均线回调（短期买点，首仓 1/3）
  条件：
    ├─ 股价回调至 50 日均线 ± 3% 范围内
    ├─ 50 日均线方向向上（斜率 > 0）
    ├─ 回调期间成交量缩至 20 日均量的 60% 以下
    └─ 日线 RSI 在 35-45 之间（没到底部但也不高）
  
  为什么这些条件：
    → 50 日均线向上 = 中期趋势良好
    → 缩量 = 卖家减少，调整接近尾声
    → RSI 35-45 = 还没超卖但已降温。RSI < 30 说明有人在强力卖出 → 可能不是回调是转折。

买点②：200 日均线回调（历史级别买点，重仓 2/3）
  条件：
    ├─ 股价回调至 200 日均线 ± 3% 范围内
    ├─ 股价 > 200 日线（碰线但不破）
    ├─ 股息率 > 近 5 年 80% 分位
    └─ 日线 MACD 底背离确认（DIF 金叉 + 放量）
  
  为什么这是"历史级别"的买点：
    → 优质消费股碰到 200 日线 + 股息率历史高位 → 通常是市场极度悲观的时候。
    → 统计上（非精确）：A 股优质消费股在 200 日均线 + 高股息率时买入，
      持有 1 年的平均回报显著高于市场。但这不意味着每次都赚钱。
    → 最大的风险：碰 200 日线后又跌破，且持续 2 周以上 → 趋势已变，止损。

买点③：重新站上 50 日均线（趋势确认买点，首仓 1/3）
  条件：
    ├─ 股价从下方向上突破 50 日均线
    ├─ 200 日均线向上（长期趋势未坏）
    ├─ 日线 MACD 在零轴附近刚金叉
    └─ 站上时放量

买点④：周线 TD 下跌 9 + 均线附近
  这是辅助信号，不单独使用。必须叠加①②③之一。

绝对不买：
  股价高于 50 日均线 > 8% → 追买。消费股 80% 的概率会回到均线。
  舍不得错过？想追的时候问自己："如果追进去明天就回调 5%，我能接受吗？"
```

### 3.4 系统三的失败模式

```
模式 A：均线失灵——股价沿着 50 日均线向下滑（温水煮青蛙）
  表现：股价碰到 50 日线不反弹，反而沿线下滑。每次"回调到位"买入都被套。
  原因：基本面在恶化（ROE 趋势性下降），市场在重新定价。
  防御：每次买入后设止损线（买入价 - 8% 或 200 日线，哪个先到）。

模式 B：消费降级（不是周期波动，是趋势性变化）
  如果消费者的购买力在结构性下降（如经济长期低迷），
  品牌消费股可能长期在低位。
  防御：观察宏观消费指标（社零、消费者信心指数）。

模式 C：股息率陷阱
  股息率高可能是因为股价跌了，也可能是因为公司提高了分红但不可持续。
  防御：检查分红率（DPS/EPS）。如果 > 90% → 不可持续，不是安全边际。
```

## 系统四：金融 — PB 区间 + MACD 优化 + 利率环境

> **核心矛盾**：金融股的本质是"利差机器"（银行）、"保费机器"（保险）、"赌场"（券商）。它们的利润高度依赖宏观变量（利率、成交额），而不是公司自身的竞争优势。所以金融股的技术分析重点不是找趋势——是在价格合适的时候买入，等估值修复就卖。

### 4.1 银行股：PB 区间的原理

```
银行的 PB 区间策略有效的原因：
  银行资产主要是贷款和债券，有市场价格（利率）和信用风险，但不会像存货一样"报废"。
  → PB 对银行有实际参考意义（不像周期股可能 PB 低是因为存货不值钱）。
  
  中国银行业的 PB 长期在 0.4-1.2 之间波动（过去 10 年）。
  → 不需要预测利润——只需要在 PB 低的时候买、PB 高的时候卖。

银行三层操作：
  低 PB 区（PB < 0.55）：买入区域。PB < 0.55 + 日线 MACD 零轴附近金叉 → 精确买点。
  中 PB 区（0.55 < PB < 0.85）：不交易。既没有安全边际，也没有泡沫。
  高 PB 区（PB > 0.9）：卖出区域。PB > 0.9 + 日线 MACD 顶背离 → 精确卖点。

⚠️ 重要修正：不同银行的"便宜 PB"不一样。
  招行（优质零售银行）：PB < 0.9 就算便宜了，PB 从未到过 0.5
  四大行（对公为主）：PB < 0.5 才算便宜
  城商行：波动大，PB < 0.4 才考虑
  → 不要用同一个 PB 阈值看所有银行。要用该银行历史上自己的 PB 分位。
```

### 4.2 保险：PEV 框架

```
保险用 PEV（Price to Embedded Value）代替 PB。
内嵌价值 = 净资产 + 有效保单的未来利润现值

中国保险股 PEV 区间：0.5-1.3（过去 10 年）
  PEV < 0.6 → 买入区域
  PEV > 1.1 → 卖出区域

保险股的额外风险：
  长端利率下行 → 保险公司的投资收益率下降 → PEV 即使低也可能更低。
  所以在买入保险股前必须先看宏观：中国 10Y 国债收益率趋势。
  → 利率下行趋势 + PEV 低 = 不是买点，是价值陷阱。
  → 利率企稳 + PEV 低 = 买点。
```

### 4.3 券商：不同于银行和保险

```
券商是"市场情绪放大器"——券商股领先大市约 1-3 个月。
不是因为券商有预知能力，是因为券商的利润（经纪/投行/自营）与市场成交量直接相关。

券商交易的核心指标（唯一的关键变量）：
  两市成交额。不是 PE，不是 PB，不是 ROE。
  牛市：成交额从 5000 亿涨到 3 万亿 → 券商涨 100-300%
  熊市：成交额从 3 万亿跌回 5000 亿 → 券商跌 50-70%

成交额判断区间（A 股，需根据当前市场结构校准）：
  成交 > 1.2 万亿且连续 5 日 → 券商有趋势行情，可以交易
  成交 0.6-1.2 万亿 → 无趋势，不参与
  成交 < 0.6 万亿 → 极度低迷，可能是券商股底部区域（但要等成交额恢复再说）

券商的 PB 区间：PB < 1.2 + 成交额开始放大 = 买。PB > 2.0 = 卖。
券商的 MACD 用法：日线 MACD 金叉仅作参考。周线级别才有意义。

不碰券商的情况：
  成交额不足 1 万亿 — 券商没有趋势行情，买了就是等。
```

### 4.4 金融股共同的宏观风险

```
利率是所有金融股的"贝塔"：
  利率下行 → 银行息差收窄、保险投资收益下降 → 利空
  利率上行 → 银行息差扩大、保险新增资金收益上升 → 利好（但存量债券跌）

→ 在降息周期中，金融股的系统一要降级（降低仓位，提高买入 PB 阈值）
→ 在利率底部区域（不再降息或开始加息预期），金融股最具配置价值
```

## 系统五：高股息防御

> **核心矛盾**：高股息股不是"买了就能躺赚"——它们在利率下行周期中表现最好，在利率上行周期中跑输。高股息股本质是"类债券"，其价格受利率驱动的程度，远超基本面驱动的程度。

### 5.1 核心驱动：利率，不是股息率本身

```
高股息股的定价逻辑：
  股息率 = DPS / 股价 → 合理的股息率应该接近无风险利率 + 风险溢价
  中国 10Y 国债 = 2.6%（当前水平 ~2026 年）
  合理的风险溢价 = 2-3%
  → 高股息股"合理"股息率 ≈ 5%
  → 股息率 > 7% = 低估。股息率 < 3% = 高估。

高股息股的买卖不是看 K 线——是看利率趋势：
  利率下行趋势 → 高股息股涨（比债券更有吸引力）
  利率上行趋势 → 高股息股跌（债券收益率追上来了）
  利率稳定 → 高股息股横盘（持有收息）

操作规则：
  10Y 国债收益率下行 + 周线 MACD 向上 → 可增配高股息
  10Y 国债收益率上行 + 周线 MACD 向下 → 减配，转向现金或短债
```

### 5.2 交易规则（简洁，因为赚的不是波动的钱）

```
买点：
  ├─ 股息率 > 5% + 股价 > 200 日均线 + 周线 MACD 向上
  └─ 买入后如果股息率跌到 < 3.5% → 卖（股价涨太多了）

卖点：
  ├─ 股息率 < 3.5% → 价格已经涨太多了
  ├─ 公司削减分红 → 核心逻辑变了
  └─ 10 年期国债收益率开始趋势性上升 → 宏观环境对高股息不利

不碰：
  高股息 + 高负债（> 70%）→ 分红可能不可持续
  高股息 + 利润下滑 → 分红可能被砍
  高股息 + 处于第四阶段的 Stock → 等趋势好了再说
```

## 六、宏观与技术面的交叉验证（全部五个系统通用）

技术面信号必须与宏观环境一致才执行。这是**防止"在熊市里完美执行了牛市系统"**的最后一道防线。

### 6.1 宏观 → 技术面的传导规则

```
宏观层（11 号 Agent）输出三个判断 → 各技术面系统执行：

宏观说：复苏初期（Pring 阶段 2，ML 复苏）
  → 系统一（周期）：可以积极，产品价格企稳就买
  → 系统二（成长）：可以积极，配合 CANSLIM M = Confirmed Uptrend
  → 系统三（消费）：可以在 50 日均线买
  → 系统四（金融）：可以开始关注银行股
  → 系统五（高股息）：不用，复苏期高股息跑输

宏观说：过热（ML 过热，Pring 阶段 4-5）
  → 系统一（周期）：最有利的阶段，但卖点比买点重要
  → 系统二（成长）：降仓，只留最强
  → 系统三（消费）：正常执行
  → 系统四（金融）：注意利率上行风险
  → 系统五（高股息）：降仓

宏观说：滞胀/衰退
  → 系统一（周期）：只卖不买
  → 系统二（成长）：清仓
  → 系统三（消费）：只在 200 日线买，轻仓
  → 系统四（金融）：不碰
  → 系统五（高股息）：如果利率在下行 → 增配
```

### 6.2 技术面信号 + 宏观矛盾 → 怎么处理

```
例：技术面 VCP 完美突破（系统二买点成立）+ 宏观说"M 在调整中"
  → 矛盾！
  → 规则：M > 个股技术面。如果 M 不好 → 任何成长股突破都不做。
  → 不是"M 不好所以不能买"——是"M 不好时 VCP 突破的假信号率翻倍"。

例：周期股产品价格大涨（系统一买点成立）+ ML 时钟说"滞胀"
  → 矛盾？
  → 不矛盾。"滞胀"= 通胀高 + 增长弱。通胀高对商品有利！
  → 产品价格涨 + 滞胀 = 可以买周期股，但必须设紧止损（滞胀可能转衰退）。

例：消费股跌到 200 日线（系统三买点②成立）+ 宏观说"经济衰退"
  → 矛盾！
  → 规则：衰退期消费股 200 日线不是买点——因为内在价值可能在下降。
  → 降级：只在股息率 > 5Y 90% 分位时才考虑（比平时的 80% 更严格）。
```

## 七、所有系统的失败模式统一表

| 失败模式 | 影响系统 | 根本原因 | 防御 |
|------|:--:|------|------|
| 用错系统 | 全部 | 把周期股当成长股、把成长股当消费股 | 第一步必判类型 |
| 大市下行 + 个股信号完美 | 二 | 牛市的技术面在熊市中失效率翻倍 | M > 个股信号 |
| 缩量突破 | 二 | 没有真正的买盘 | 突破日量必须 > 1.5×50日均量 |
| 背离无确认就行动 | 全部 | 背离是衰竭信号，不是反转信号 | 必须等确认（放量阳/阴线） |
| 周期底部被当结构衰退 | 一 | 没判断产品长期需求趋势 | 问"10 年后需求还在吗" |
| 均线回归在第四次失败 | 三 | 基本面在恶化，不是正常回调 | 设硬止损（-8% 或 200 日线破） |
| PB 低但 ROE 为负 | 一/四 | 价值陷阱——低价反映真实恶化 | ROE > 0 是底线 |
| 情绪驱动追涨 | 二/三 | FOMO | 与 14 号 Agent 纪律联动 |

## 八、执行决策树（必须逐条走完）

```
Step 0：判类型（5 秒）→ 主题炒作 = 跳过

Step 1：查宏观（参考 11 号 Agent 输出）
  ├─ 宏观对当前系统有利 → 正常执行
  ├─ 宏观对当前系统中性 → 降仓位执行
  └─ 宏观对当前系统不利 → 至少等一周，观察

Step 2：逐条对照买点（完成度评分）
  ├─ 满足所有核心条件 → 买点成立（标注哪些是"完美满足"，哪些是"勉强满足"）
  ├─ 满足 > 60% → 可以买但降仓位 + 标注缺少什么
  └─ 满足 < 60% → 等

Step 3：输出交易计划
  ├─ 买价 / 买量 / 止损价 / 目标卖点
  ├─ 止损价不是建议——是下单时同时设置的止损单
  └─ 如果止损距离 > 10%（对系统二 > 10%，对系统一/三 > 12%）→ 调整仓位使单笔亏损 < 总资产 2%

Step 4：输出确定结论
  ├─ 买（+ 什么价 + 多少 + 止损 + 什么条件卖 + 什么条件证明我错了）
  ├─ 等（+ 等什么 + 现在缺什么 + 如果等不到怎么办）
  └─ 不碰（+ 为什么 + 什么条件下重新考虑）

Step 5：记录（与 01/14 号 Agent 联动）
  └─ 写：为什么在这个时间点，用这个系统，买这个价格的这只股票
```
