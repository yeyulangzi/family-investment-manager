## 诊断流程

| A 股权益 | | | 30% | |
| 全球权益 | | | 20% | |
| 黄金 | | | | |
| 其他 | | | | |

### 2. 现金流和安全垫
- 现金 ≥ 140 万执行舒适线？硬底线 100 万是否安全？
- 收入空窗期：月支出 ~15,500，现金能撑多久？

### 3. IPS 偏离度检查
- 哪些类别偏离 > 5%？哪些风险桶超配？
- 回撤纪律：金融资产从高点回撤是否触及 5% 预警 / 8% 硬上限？

### 4. 集中度风险检查（新增）

| 维度 | 检查 | 警戒线 |
|------|------|------|
| 单标的集中度 | 任一个股/基金占金融资产比 | > 10% 警戒，> 15% 强制分散 |
| 行业集中度 | 中国互联网 / 科技 / 金融等 | > 30% 警戒 |
| 地域集中度 | A 股 vs 港股 vs 美股 | 任一类 > 50% 提示 |
| 币种集中度 | RMB vs HKD vs USD | RMB > 70% 提示汇率风险 |
| 相关性风险 | 持仓间相关系数 | > 0.8 的高相关对，标注"分散效果有限" |

### 5. 压力测试
- 权益 -30%：金融资产回撤多少？是否触及 8% 硬上限？
- 收入中断 6 个月：现金跌破 100 万？
- 房价 -20%：净资产影响？
- 最大持仓标的 -50%：组合冲击？

### 6. 诊断结论
- 当前状态：健康 / 关注 / 警戒
- 偏离项及修正方向 + 优先级排序

## 配置流程

### 前置：必须先走诊断流程

### 1. 资金属性判断
- 长期（5 年+）/ 中期（1-5 年）/ 短期（< 1 年）/ 应急？
- 收入空窗期：不将应急缓冲资金投入权益

### 2. IPS 对齐 + 再平衡规则

| 偏离幅度 | 动作 |
|------|------|
| < 5% | 无需操作 |
| 5%-10% | 评估是否触发再平衡（考虑交易成本） |
| > 10% | **必须再平衡**，分 2-3 批执行 |

优先级：先降超标风险桶 → 再补低配类别。新增资金优先补最低配类别。

### 3. 组合效率检查
- 每单位风险（波动率/最大回撤）的预期回报是否合理？
- 是否有"零贡献分散"的持仓？（相关性 > 0.9 的两个标的 → 合并或二选一）

### 4. 执行方案
- 具体标的 / 金额 / 分批节奏
- **必须写「不做什么」**
- 标的推荐走对应子 Agent（个股→03，基金→15，行业→17）

### 5. 约束检查
- 不因配置让现金跌破 100 万硬底线
- 中国互联网风险桶「只降不增」仍有效
- 个股禁止令仍有效
- 再平衡不触发大额税务事件（如适用）
