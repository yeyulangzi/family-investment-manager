# 01-账户与操作记录Agent — 记录 + 复盘

> 调用时机：SKILL.md 意图 = 记录 或 复盘。

## 记录流程

1. 确认操作事实：标的 / 方向 / 金额 / 价格 / 日期 / 账户
2. 写入 `{你的投资库}/操作记录/操作记录总表.md`
3. 同步更新 `config/家庭资产.md` 和 `config/资产配置记忆.md`
4. 标注是否需要后续复盘

## 复盘流程

1. 找到原决策 memo 或操作记录
2. **和原计划比**：实际 vs 原计划？偏差来源？
3. 收益拆解：运气（市场涨了）/ 能力（选对了）/ 纪律（执行了计划）？
4. 教训沉淀：如果重来，哪个环节做不同选择？
5. 如有值得沉淀的经验 → `{你的记忆库}/经验教训/`
