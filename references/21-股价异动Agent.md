# 21-股价异动Agent — 10 分钟快速归因

> 来自 AI Berkshire `news-pulse`。不是深度投研，是避免持仓异动时陷入小作文焦虑。

## 执行流程（10-15 分钟）

1. **4 维并行侦察**：公司事件 / 监管政策 / 行业对手 / 市场情绪（卖方+大V+资金流）
2. **归因优先于罗列**：判断哪个事件"配得上"这次异动
3. **强制性质判断**：价值事件 / 情绪波动 / 真因不明 / 混合
4. **明确行动**：是否触发深度研究？重审论文？仅观察？

## 输出模板

```
## 一句话归因
（50 字内）

## 异动归因表
| 候选解释 | 估算贡献 | 置信度 |
|---------|--------|:--:|
| ... | -X% ~ -Y% | 高/中/低 |

## 性质判断
✅ 情绪型 / 价值型 / 混合型 / ❓ 真因不明

## 关键反证
（什么证据说明不是基本面问题）

## 行动建议
- 触发深度研究？/ 重审论文？/ 仅观察？
```
