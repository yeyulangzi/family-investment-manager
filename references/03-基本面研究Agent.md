### 信息丰富度评级（每家公司必标）

| 等级 | 判断标准 | 对分析的影响 |
|------|---------|-------------|
| **A 级** | 上市多年、数据充裕 | 正常，但警惕共识陷阱 |

## 18 步完整链路

### 步骤 1：当前组合和操作记录
- 已有持仓、成本、仓位、浮盈亏
- 本次操作改变什么暴露？

### 步骤 2：信息缺口
- 列出缺失关键数据，标注「不补会怎样」

### 步骤 3：生意本质
- [ ] 一句话：客户问题 → 产品 → 收费 → 利润
- [ ] 赛道定义：真正垄断/控制了什么？别人能不能复制？
- ❌ 禁止：用行业标签代替生意本质

### 步骤 4：商业模式拆解
- 收入/成本结构、利润引擎
- 交易型/订阅型/项目型？飞轮加速还是减速？

### 步骤 5：行业结构
- [ ] 波特五力 + 行业利润被谁拿走？
- [ ] 大市场 ≠ 好生意

### 步骤 6：护城河
- [ ] 每个护城河类型 + 证据 + 反证 + 可观察跟踪指标
- [ ] 冲击韧性：历史上经历什么冲击？变强还是变弱？
- [ ] 核心算法（创生公式）：X→Y→Z→回到X

### 步骤 7：财务质量
- [ ] 利润表/资产负债表/现金流量表
- [ ] FCF vs 净利润差距必须解释（> 30% 时）
- [ ] ROE/ROIC 拆解

### 步骤 8：管理层与资本配置
- 诚实？理性？承诺兑现？
- 创始人 vs 职业经理人？公司依赖人还是系统？
- 管理层纵深（管理层持股 > 30% 或创始人掌舵时启用）

### 步骤 9：核心假设
- [ ] 最依赖哪 1-3 个假设？
- [ ] 每个假设的反证指标 + 失效条件
- ❌ 禁止：没有反证指标的假设

### 步骤 10：估值
> 详见 `估值与安全边际方法论.md`

- [ ] 先反推隐含预期
- [ ] 选匹配方法（DCF/倍数/资产/分部/周期）
- [ ] 倍数和增长/ROIC/风险一起看
- [ ] 安全边际四个来源（价格折扣/资产保护/生意质量/组合约束）
- [ ] **10 年 25x PE 退出法**：年化 < 10% → 不具备安全边际
- [ ] 买入区间分层：观察价/初买价/重买价/停止买入价
- ❌ 禁止：周期峰值利润算 PE / 估值精确到小数点后

### 步骤 11：三情景 + 镜子测试

| 情景 | 假设 | 概率 | 隐含回报 |
|------|------|:--:|------|
| 悲观 | | | |
| 中性 | | | |
| 乐观 | | | |

> "我以 ___元 买入 ___公司，因为：
> 1. 生意本质是___，我理解它的赚钱方式；
> 2. 护城河是___，且在变宽/变窄；
> 3. 管理层___，值得/不值得信赖，因为___；
> 4. 当前价格相当于内在价值___折，有/无安全边际；
> 5. 即使我错了，下行风险可控/不可控，因为___。"

**5 句话说不完整 = 不买。**

### 步骤 12：技术面（仅执行参考）
> 详见 `多流派投资分析完整工作流.md` 第 6 节

- [ ] 趋势结构 / 均线 / 量价 / 动量(RSI/MACD) / 支撑压力 / 执行参考
- ❌ 禁止：因技术形态好看而买入

### 步骤 13：宏观周期
> 详见 `多流派投资分析完整工作流.md` 第 7 节

- [ ] 利率/通胀/汇率/周期位置/市场风格

### 步骤 14：多流派交叉验证

**格雷厄姆**（安全边际/清算价值）
**巴菲特**（护城河/长期复利/好生意≠好投资）
**费雪**（成长质量）
**ljg-invest**（秩序创造 vs 搬运）

**段永平（不为清单）**：
- No margin / 不做空 / 不投不懂 / 不频繁交易？
- 能封仓十年吗？在做「对的事情」还是「把事情做对」？

**芒格（逆向检验 7 问）**：
1. 做空报告怎么写？
2. 3 个死亡场景？
3. 最强不买理由？为什么没说服我？
4. 历史类比：谁在类似情况下失败了？
5. 三年后最可能的错误？
6. 亏 50% 最可能的原因？能接受吗？
7. 最脆弱的事实是什么？

**投资风格交叉验证**（方法论第 8 节）：质量/成长/GARP/逆向/事件驱动

### 步骤 15：行为金融自检
- [ ] 追涨？补仓冲动？确认偏误？锚定？熟悉度偏误？
- [ ] 如果今天从零建仓，还会买吗？

### 步骤 16：风险与仓位
- 单标的最坏回撤 / 相关性 / 流动性
- 仓位上限（占权益/金融资产/总资产）

### 步骤 17：最强反方观点
- [ ] 三视角对抗：保守价值/逆向怀疑/趋势行为
- [ ] 交集和矛盾点显式列出
- ❌ 禁止：用「综合来看」模糊收口

### 步骤 18：最终动作
- [ ] 判断等级：通过/灰色/不通过
- [ ] 具体动作 + 量 + 条件 + 硬截止日期 + 复盘时间
- [ ] 家庭财务闸门状态 + SOFT-GATE 限制标注
- [ ] **好生意 ≠ 好投资**：分开判断
- ❌ 无动作 = 没做完

## 历史案例库——每个检查点背后的真实失败

> 为什么要有案例库？因为抽象规则容易被忽略。一个真实的、惨烈的案例，比十个"你应该检查 X"的提醒更有用。

### 案例 1：商业模式——"说不清楚怎么赚钱"（瑞幸咖啡 2019-2020）

```
检查点：步骤 3「说不清楚怎么赚钱 → HARD-GATE」

瑞幸 2019 年的故事：
  "中国咖啡市场巨大" + "数字化新零售" + "闪电扩张"
  
检查点追问：
  ① 客户问题：中国人不喝咖啡，你要解决什么问题？
     → 瑞幸的答案：用补贴让人养成喝咖啡习惯。但补贴停了人还会喝吗？
  ② 产品：咖啡和其他咖啡有什么不同？
     → 没有。就是便宜的咖啡。
  ③ 收费：每杯卖多少钱？成本多少？
     → 售价 < 成本，每卖一杯亏一杯。
  ④ 利润：什么时候赚钱？
     → "规模起来后就赚钱了"——但规模越大亏得越多。

HARD-GATE 触发：说不清楚怎么赚钱 → 不该买。
结果：2020 年自曝 22 亿收入造假，股价从 $50 跌到 $1。

教训：不是所有"说不清楚"都会造假，但所有造假都"说不清楚"。
     如果一家公司的赚钱方式让你觉得"说不清但感觉很厉害"→ 不是它厉害，是你没看懂。
```

### 案例 2：护城河——"护城河在变窄"（格力电器 2018-2024）

```
检查点：步骤 6「护城河评估 + 冲击韧性」

格力 2018 年的护城河：
  ✓ 品牌（"好空调格力造"）
  ✓ 渠道（全国经销商网络）
  ✓ 规模（全球最大空调制造商）

检查点追问（2018 年应该问但没人问的）：
  ├─ 渠道护城河在电商时代还有效吗？
  │   → 2018 年天猫/京东空调销量增速 > 50%，格力线上占比 < 15%
  │   → 经销商体系从"资产"变成"包袱"——因为线上价格透明，线下加价卖不动
  ├─ 品牌护城河对年轻人还有效吗？
  │   → 小米/美的在年轻消费者中的认知度快速上升
  └─ 冲击韧性：如果行业出现价格战，格力能扛住吗？
      → 2019 年美的发起价格战，格力被迫跟进，利润率从 15% 降到 10%

结果：格力股价从 2018 年高点 ~65 元，到 2024 年仍在 35-45 元区间。6 年零回报。

教训：护城河不是"有"或"没有"——是"在变宽还是变窄"。
     格力的护城河在 2018 年看起来很强——但每一条都在被时代侵蚀。
     → 护城河评估必须包括「未来 5 年护城河可能被什么侵蚀？」
```

### 案例 3：管理层——"管理层在悄悄减持"（大量 A 股公司）

```
检查点：步骤 8「管理层与资本配置」

管理层危险的信号（不是"证明有问题"，是"需要深挖"）：

① 董事长/CEO 在股价高位密集减持
   → 理由通常是"个人资金需求"——但如果真的看好公司未来，
     为什么不质押股票贷款而要卖？（减持是永久的，贷款是临时的）

② CFO 频繁更换
   → CFO 是最了解公司财务真实情况的人。
     如果 CFO 每 1-2 年换一次 → 可能是因为"谁都不愿意签字"。

③ 关联交易比例高且增长
   → 上市公司和董事长控制的私人公司之间交易增加 → 利润可能在转移。

④ 股权激励条件太容易达成
   → 如果行权条件 = "营收增长 5%" → 这不是激励，是送钱。

⑤ 分红率极低 + 账上现金极高 + 同时大量融资
   → "存贷双高"——经典造假信号（康得新、康美药业）。

这些信号单独出现不说明什么——但 3 个以上同时出现 → 🚨
```

### 案例 4：估值——"周期顶部利润算 PE"（中远海控 2021）

```
检查点：步骤 10「禁止：周期峰值利润算 PE」

2021 年中远海控：
  利润：893 亿（历史新高，2020 年才 99 亿）
  PE：约 3 倍（看起来"极便宜"！）
  
如果按当时的利润算 PE → 3 倍 PE → "极度低估" → 重仓买入

但错了。因为：
  ├─ 893 亿利润是航运运价在历史极端高位的结果
  ├─ 运价不是永久性的——2020-2021 是疫情供应链紊乱 + 补库需求叠加
  └─ 用周期顶峰利润算 PE = 用最好的年景当永久年景

正确做法（步骤 10 的规则）：
  ├─ 取过去 5-10 年"正常化"利润（剔除极端值）
  ├─ 中远海控 2015-2019 年平均利润 ≈ 30-50 亿
  └─ 正常化 PE ≈ 3000 亿市值 / 40 亿利润 ≈ 75 倍（不是 3 倍！）

结果：中远海控 2021 年 7 月见顶 ~25 元，2022 年底回到 ~10 元。跌幅 60%。

教训：如果有人跟你说"PE 才 3 倍太便宜了"→ 先问他"这个利润能持续吗？"。
     周期股的低 PE 不是一个机会——是一个警告。意味着利润已经在顶峰了。
```

## 行业特定深度模块

> 不同行业的"关键问题"完全不同。以下是最常见的五类行业的深度检查点。
> 用 17-行业研究Agent 做完整 8 步行业分析。这里的模块是基本面分析的行业补充。

### 模块 A：互联网平台

```
必问的 5 个问题（互联网平台特有的分析维度）：

1. 网络效应是双边还是多边？强还是弱？
   双边（淘宝：买家↔卖家）→ 中等。多边（微信：用户↔用户↔商家↔内容）→ 最强
   
2. 用户时长是在增长还是被蚕食？
   看：QuestMobile/极光大数据。不是看 MAU 总量——是看人均使用时长。
   如果时长在降 → 平台在失去用户的心智。

3. 货币化率（Take Rate）的上升空间和天花板？
   电商：淘宝 ~4%，拼多多 ~3%，京东 ~7%（自营为主不可比）
   如果 Take Rate 已经 > 8% → 继续提升的空间有限且会引起商家反弹

4. 监管风险属于"行业性的"还是"公司特有的"？
   反垄断 → 行业性（所有大平台都受影响，估值一起降）
   数据安全审查 → 视具体业务（出海 vs 国内不同）

5. 第二增长曲线有吗？靠谱吗？
   云计算（阿里）→ 靠谱但增速放缓
   AI（百度）→ 方向对但商业化路径不明
   出海（拼多多/Temu）→ 增长快但地缘政治风险大
```

### 模块 B：消费品牌

```
必问的 5 个问题：

1. 提价能力——过去 3 年提价了几次？销量跟上了吗？
   如果提价后销量不降 → 强品牌。提价后销量下降 → 品牌溢价在减弱。

2. 渠道变革——直销占比在上升还是下降？
   直销占比上升 → 公司对终端价格和用户体验控制力增强 → 好信号。
   但也要看：直销增加的是利润率还是费用率？

3. 复购率——消费者买了一次后还会再买吗？
   调味品/乳业/白酒：高复购，天然好生意
   小家电/服装：低复购，需要不断获客

4. 年轻化——品牌在老化和被新一代抛弃吗？
   看：社交媒体上的提及量、电商搜索趋势、年轻消费者占比
   如果 35 岁以上消费者 > 70% → 品牌在老化

5. 品类天花板——这个品类本身还在增长吗？
   方便面 → 见顶/下降。预制菜 → 增长。运动服饰 → 还在增长。
   在夕阳品类里做最好的品牌 → 也只能赚夕阳的钱。
```

### 模块 C：金融（银行/保险）

```
必问的 5 个问题：

1. 资产质量——不良率是真还是假？
   看：逾期 90 天以上 / 不良贷款 > 1 → 不良认定宽松，在藏坏账
   看：关注类贷款占比 → 关注类越多，未来变成不良的越多

2. 净息差趋势——利差在扩大还是收窄？
   银行的核心利润来源。降息周期中息差收窄 → 利润承压
   活期存款占比高的银行 → 降息时息差损伤更小

3. 资本充足率——还能增长吗？
   资本充足率接近监管红线 → 要么减少分红，要么股权融资（摊薄现有股东）

4. 拨备覆盖率——是"隐藏利润"还是"不够安全"？
   拨备覆盖率 > 300% → 可能故意多计提，隐藏利润（平滑未来业绩）
   拨备覆盖率 < 150% → 不够安全，不良增加时没有缓冲

5. 分红可持续性——分红率 > 30% 能维持吗？
   利润增长 + 资本充足 → 分红可持续
   利润下降 + 资本紧张 → 分红可能被砍
```
