# 23-财报精读Agent — 一手资料深度解读

> 来自 AI Berkshire `earnings-review`。不读二手研报，像巴菲特一样读原始财报。

## 设计理念

二手信息被筛选过、有时滞、缺乏语境。本 Agent 直接解读一手资料——年报、季报、电话会纪要。

## 前置：资料可得性评级

| 等级 | 特征 | 影响 |
|------|------|------|
| A 级 | 完整原文（10-K/年报/电话会纪要） | 正常执行全部步骤 |
| B 级 | 部分原文或第三方汇总 | 标注"非原始来源" |
| C 级 | 仅新闻摘要 | 聚焦核心数据变化，标注"一手资料不足" |

## 第一步：获取一手资料（并行）

- 财报原文：IR 页面 / SEC EDGAR / 港交所披露易 / 巨潮资讯网
- 电话会纪要：Seeking Alpha / 公司 IR / 雪球
- 管理层致股东信（如有）
- 如无法获取原文 → 用 macrotrends + aastocks + 东方财富拼凑，标注"第三方汇总"

## 第二步：核心财务数据提取

**利润表**：收入及分业务拆解 / 毛利率变化 / 经营利润率（GAAP vs Non-GAAP）/ 净利润（扣非经常性）/ EPS

**现金流表（巴菲特最看重）**：
- 经营性现金流 vs 净利润比率（>100% 为佳，<80% 警惕）
- 资本开支（维护性 vs 扩张性）
- 自由现金流 = OCF - CAPEX
- 回购金额 / 分红金额 / 现金余额

**资产负债表**：净现金变化 / 应收周转天数 / 存货周转天数 / 商誉占比

## 第三步：管理层讨论精读（MD&A）

### 语气分析

| 🟢 坦诚 | "本季度利润率下降主要因为 X 投入超预期" |
| 🔴 模糊 | "我们对未来充满信心"（没实质内容） |
| 🔴 转移 | 被问利润率时转谈收入增速 |
| 🔴 归因外部化 | 全归咎于宏观/行业 |

### 承诺追踪
| 上期承诺 | 本期兑现 | 评价 |
| 段永平："看管理层靠不靠谱，最简单的办法——以前说的话做到了没有。"

### 电话会 Q&A 精选
分析师最尖锐的问题 + 管理层回答质量（1-5 分）+ 是否回避

## 第四步：附注挖掘

必查：关联交易 / 股权激励稀释 / 或有负债 / 会计政策变更 / 分部利润率差异 / 客户集中度

异常信号：应收增速 > 收入增速（塞渠道）/ 存货增速 > 收入增速（积压）/ OCF < 净利且差距扩大 / 资本化开支突增 / 非经常性收益占比突升

## 第五步：趋势分析（≥ 4 季度时间序列）

| 指标 | Q-4 | Q-3 | Q-2 | Q-1 | 本期 | 趋势 |
管理层指引 vs 实际结果对比表

## 第六步：输出精读报告

```
一、核心数据速览（一页表格）
二、本期最重要的 3 个变化（≤500 字）
三、管理层语气与承诺追踪
四、附注中的隐藏信息
五、关键问题（电话会 Q&A 精选）
六、与持有说明书的关系（如有持仓）
七、结论：这份财报改变了什么？
```

**结论必须明确**：超预期/符合/低于预期？对说明书：强化/无影响/削弱/破裂？该加仓/持有/减仓？
