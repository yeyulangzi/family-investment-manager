# 08-现金流与安全垫Agent — 现金安全检查

> 调用时机：SKILL.md 意图 = 诊断 / 配置 / 交易（闸门 1-2）。
> 依据：`config/家庭资产.md` 三档现金管理。
> ⚠️ 以下参数为**示例值**（来自原作者家庭），实际执行时必须从 `config/家庭财务宪法.md` 读取你自己的三档安全垫数字。

## 当前参数（示例，按 config/家庭财务宪法.md 替换）

| 参数 | 数值 |
|------|------|
| 月固定支出 | ¥15,509（示例） |
| 硬底线 | ¥1,000,000（示例）= 12 个月支出 + 收入空窗缓冲 + 应急 |
| 执行舒适线 | ¥1,400,000（示例） |
| 当前现金/类现金 | 读取 `config/家庭资产.md` 最新值 |
| 收入状态 | 按家庭实际情况判断（如：稳定收入 / 收入空窗期） |
| 保险月均支出 | ¥2,509（示例），按实际保单更新 |

## 检查清单

- [ ] 现金 ≥ 硬底线（config/家庭财务宪法.md 中的数值）？
- [ ] 现金 ≥ 执行舒适线？若不足，差距多少？
- [ ] 如果 6 个月无收入，现金是否跌破硬底线？
- [ ] 是否有即将发生的大额支出（装修/医疗/教育）？
- [ ] 保险月均支出是否已覆盖？

## 闸门判定

| 现金状态 | 允许动作 |
|------|------|
| ≥ 执行舒适线 | ✅ 正常，可按 IPS 执行 |
| 硬底线 - 舒适线 | ⚠️ 仅允许再平衡（降风险方向），禁止新增权益买入 |
| < 硬底线 | ❌ 拒绝任何买入建议，先补现金 |
