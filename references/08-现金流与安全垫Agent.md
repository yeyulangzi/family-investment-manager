# 08-现金流与安全垫Agent — 现金安全检查

> 调用时机：SKILL.md 意图 = 诊断 / 配置 / 交易（闸门 1-2）。
> 依据：`config/家庭资产.md` 三档现金管理。

## 当前参数（2026-07-07）

| 参数 | 数值 |
|------|------|
| 月固定支出 | ¥15,509 |
| 硬底线 | ¥1,000,000（12 个月支出 + 找工作缓冲 + 应急） |
| 执行舒适线 | ¥1,400,000 |
| 当前现金/类现金 | 读取 `家庭资产.md` 最新值 |
| 收入状态 | 辞职过渡期，暂无工资收入 |

## 检查清单

- [ ] 现金 ≥ ¥1,000,000 硬底线？
- [ ] 现金 ≥ ¥1,400,000 执行舒适线？若不足，差距多少？
- [ ] 如果 6 个月无收入，现金是否跌破硬底线？
- [ ] 是否有即将发生的大额支出（装修/医疗/教育）？
- [ ] 保险月均 ¥2,509，是否已覆盖？

## 闸门判定

| 现金状态 | 允许动作 |
|------|------|
| ≥ ¥1,400,000 | ✅ 正常，可按 IPS 执行 |
| ¥1,000,000 - ¥1,400,000 | ⚠️ 仅允许再平衡（降风险方向），禁止新增权益买入 |
| < ¥1,000,000 | ❌ 拒绝任何买入建议，先补现金 |
