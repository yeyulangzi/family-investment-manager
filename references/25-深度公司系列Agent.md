# 25-深度公司系列Agent — 8 篇长文拆一家公司

> 来自 AI Berkshire `deep-company-series`。不适合单篇研报场景（用 03-基本面），用于深度写作/发布。

## 8 篇模板

| # | 篇名 | 核心问题 | 字数 |
|---|------|---------|------|
| 01 | 你以为你看懂了 X，其实没有 | 认知重置：破 3 个常见错觉 | 4-5k |
| 02 | X 的护城河 | 护城河深不深、5/10 年后还在吗 | 6-8k |
| 03 | X 的最大利润引擎 | 主业是什么、为什么能持续 | 6-8k |
| 04 | X 藏在账上的另一家公司 | 投资组合/子公司/隐藏价值 | 8-10k |
| 05 | AI 时代 X 是赢家还是输家 | 时代变量：分业务拆影响 | 8-10k |
| 06 | 用巴菲特方式拆 X 的财报 | 毛利率/FCF/ROE/SBC | 8-10k |
| 07 | X 的管理层值不值得托付 | 资本配置+诚信+接班人 | 8-10k |
| 08 | 多少钱值得买，什么信号必须卖 | DCF 三情景+红线+仓位 | 10-12k |

## 写作规范

- **第一句就给数字或反常识结论**，前 18-20 字独立站住
- **不用**：显然/必然/一定/我认为/完美/教科书级别
- **标题用反差数字**（"15 年 7 次挑战全失败"），不用"小巴菲特""中国版 X"
- **每个核心判断附反方观察**

## 事实核查 Checklist

**写前警惕**：不线性外推增速 / 不主观概率加权 / 第三方 MAU 口径差异大 / 单一归因
**写后扫描**：跨篇数字一致性 / 口径标注 / 绝对化表述弱化 / 第三方来源标注

## 执行流程

1. 调研：读 5 年年报 + 3 份卖方研报 + 用 `03-基本面` 生成底稿
2. 写作：按 01→08 顺序，每篇独立成文但贯穿同一套估值/管理层/价格判断
3. 跨篇扫描：市值/净利润/持股比全系列对齐
4. 发布前 grep 扫描个人信息

保存：`{你的投资库}/公司分析/{公司名}/《看懂{公司名}》/`
